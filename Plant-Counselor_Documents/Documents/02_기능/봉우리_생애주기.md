# 봉우리 생애주기

> 봉우리(Bud) = 하나의 고민 또는 일정. 정원의 가장 작은 단위.

관련 문서: [[식물]], [[상태_자동전이]], [[Bud_JSON]], [[Skills/update_bud_status]], [[Skills/update_bud_progress]], [[Skills/abandon_bud]], [[Skills/harvest_bud]]

---

## 상태 목록

| 상태 | 의미 | 시각 표현 |
|---|---|---|
| `seed` | 생성 직후 | 작은 점/씨앗 |
| `bud` | 인식되어 매달림 | 닫힌 봉오리 |
| `flower` | 활발히 진행 중 | 활짝 핀 꽃 |
| `fruit` | 마무리 직전 | 익은 열매 |
| `harvested` | 완료 | 수확됨(보관함으로 이동) |
| `wilting` | 정체 상태 | 갈변/축 처짐 |
| `rot` | 포기됨 | 검게 변함, 일정 시간 후 사라짐 |

---

## 정상 흐름

`seed → bud → flower → fruit → harvested`

- **seed → bud**: 생성 직후 자동(즉시 또는 매우 짧은 지연).
- **bud → flower**: 사용자가 "본격적으로 진행 중"이라고 발화하거나 [[Bud_JSON#progress]]가 임계 이상.
- **flower → fruit**: 마무리 단계 발화 또는 진행률 임계 이상.
- **fruit → harvested**: "끝났어", "해결됐어" 등 완료 발화. [[Skills/harvest_bud]] 호출.

---

## 분기 흐름

- **Any → wilting**: 일정 기간 변화 없음. [[상태_자동전이]]가 자동 처리.
- **Any → rot**: 사용자의 명시적 포기 발화. [[Skills/abandon_bud]] 호출.
- **wilting → flower/bud**: 사용자가 다시 진행을 알릴 경우 [[Skills/update_bud_status]]로 복귀.
- **rot → 사라짐**: [[설정#3-정원-규칙]]의 기간이 지나면 시각적으로 사라짐. 데이터는 보존.

---

## 진행률(progress)

- 0~100 정수.
- LLM이 사용자 발화에서 추정해 [[Skills/update_bud_progress]]로 갱신.
- 직접 숫자로 말해도 되고("이거 한 60% 된 것 같아") 정성적으로 말해도 된다("거의 다 끝났어").

---

## 상태 변경 이력

[[Bud_JSON#history]]에 매 전이마다 다음 정보를 누적한다.

- `from`, `to` 상태
- `at` (ISO 시각)
- `reason` (LLM 또는 자동 엔진이 기록한 짧은 이유)

이력은 [[식물#봉우리-상세-패널]]과 [[Skills/search_conversation]]에서 참고된다.

---

## 마감일

- 선택적. 있으면 [[캘린더]]와 [[알림]]에서 사용된다.
- 마감일 변경은 [[Skills/set_deadline]]을 통해서만.

---

## 타입(고민/일정)

- `concern`(고민) 또는 `schedule`(일정).
- 생성 시 LLM이 추정하지만 사용자가 발화로 바꿀 수 있다.
- 통계 [[통계_시스템]]에서 카운트가 분리된다.
