# 설정 페이지

관련 문서: [[홈]], [[데이터_백업_복구]], [[회원가입_로그인]], [[시스템_프롬프트]], [[폴더_구조]]

---

## 섹션 구성

설정 페이지는 좌측 탭으로 다음 섹션을 가진다.

1. 계정
2. AI 설정
3. 정원 규칙
4. 시각/사운드
5. 데이터
6. 정보

---

## 1. 계정

- 현재 로그인 사용자 이름 표시.
- 로그아웃 버튼.
- 비밀번호 변경(현재 비번 확인 → 새 비번 2회 입력).
- 닉네임 변경.
- 계정 데이터 내보내기 → 사용자 폴더를 zip으로 압축. 자세히는 [[데이터_백업_복구#내보내기]].
- 계정 데이터 가져오기 → zip을 받아 사용자 폴더로 복원. 자세히는 [[데이터_백업_복구#가져오기]].
- 계정 삭제 → 확인 모달 후 [[폴더_구조]]의 사용자 폴더를 제거.

---

## 2. AI 설정

- LLM 모델 선택(목록은 [[AI_연동#모델-카탈로그]] 참고).
- API 키 입력 — 키는 [[User_JSON]] 외부의 별도 키스토어 파일에 저장(평문 권장하지 않음, 자세히는 [[AI_연동#키-저장]]).
- AI 응답 톤:
  - 따뜻한 상담사
  - 담백한 비서
  - 친구
- AI가 사용자를 부르는 호칭(닉네임 외 별도 설정 가능).
- 자발적 발화 활성/비활성(접속 시 브리핑, 시듦 알림 등).

설정 변경은 [[시스템_프롬프트]]의 변수에 반영된다.

---

## 3. 정원 규칙

- 시듦 임계 일수(기본 7일).
- 시듦에서 추가 정체 시 AI 회고 제안 일수(기본 +7일).
- 썩음 후 사라지기까지의 일수(기본 14일, 데이터는 보관).
- 자동 상태 전이 사용 여부(꺼두면 사용자 발화 기반으로만 전이).
- 마감일 임박 알림 기준일(기본 3일 전).

세부 규칙은 [[상태_자동전이]]와 [[알림]] 참고.

---

## 4. 시각/사운드

- 배경 테마:
  - 봄/여름/가을/겨울 정원
  - 야간 정원
  - 자동(현재 계절 추정)
- 효과음 on/off, 볼륨.
- BGM on/off, 볼륨.
- 식물 애니메이션 강도(없음/은은함/풍부함) — 저사양 PC 대응.

---

## 5. 데이터

- 로컬 데이터 폴더 위치 표시 및 탐색기 열기 버튼. 위치는 [[폴더_구조]] 참고.
- 백업 만들기, 백업 목록, 백업으로 복구. [[데이터_백업_복구]]
- 대화 로그 삭제(식물/봉우리는 유지). [[ConversationLog_JSON]]을 비움.
- 데이터 무결성 검사 — JSON 파일 손상 여부 검사 후 보고.

---

## 6. 정보

- 앱 버전
- 라이선스
- 도움말 링크
- 데이터가 외부로 나가는 범위(LLM API 호출에 한함) 명시.
