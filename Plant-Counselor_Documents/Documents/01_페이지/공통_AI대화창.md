# 공통 AI 대화창

> 어디서나 호출되는 LLM 대화 인터페이스의 동작 규칙.

관련 문서: [[LLM_흐름]], [[시스템_프롬프트]], [[Skill_개요]], [[ConversationLog_JSON]]

---

## 호출 방법

- 모든 화면 우측 하단의 떠 있는 "정원사" 버튼.
- 단축키(예: 스페이스바 길게 누름, 설정 가능).
- 특정 봉우리/식물의 "AI에게 묻기" 메뉴.

---

## 컨텍스트 자동 주입

대화창이 열릴 때 다음 정보가 [[시스템_프롬프트]] 변수와 함께 LLM에 전달된다.

| 컨텍스트 종류 | 내용 |
|---|---|
| 사용자 프로필 | 닉네임, 호칭, 톤 설정 |
| 현재 화면 | "홈" / "식물 목록" / "식물 상세(분야명)" / "봉우리 상세(제목)" / "설정" |
| 활성 통계 요약 | 진행 중 수, 시듦 수, 이번 달 수확 수 등 |
| 선택된 객체 | 식물 id, 봉우리 id (해당 시) |
| 최근 대화 로그 | 같은 스코프의 마지막 N개 메시지 |

---

## 표시 영역

- 상단: 현재 컨텍스트 배지(예: `식물: 학업 > 봉우리: 기말 프로젝트`).
- 중앙: 메시지 히스토리. 사용자/AI 메시지 구분.
- AI 메시지 안에 Skill 실행 결과를 인용한 카드가 표시될 수 있다(예: 봉우리 생성됨).
- 하단: 입력창과 전송 버튼.

---

## 메시지 처리 흐름

1. 사용자가 발화 입력.
2. [[LLM_흐름]]에 따라 의도 분류 + Skill 후보 결정.
3. 확인이 필요한 경우 AI가 사용자에게 되묻는다("이 식물에 새 꽃을 피울까요?").
4. 사용자 동의 시 LLM이 해당 [[Skill_개요]] 호출.
5. Skill 실행 결과를 LLM이 자연어로 풀어 응답.
6. 메시지/스킬 호출 기록이 [[ConversationLog_JSON]]에 누적.

---

## 스코프 종류

대화 로그는 다음 스코프 중 하나에 묶인다.

- `global` — 어디서 시작했는지 알 수 없는 일반 대화.
- `plant:<plant_id>` — 식물 컨텍스트에서 시작.
- `bud:<bud_id>` — 봉우리 컨텍스트에서 시작.

스코프에 따라 [[Skills/search_conversation]]이 검색 범위를 좁힐 수 있다.

---

## 확인이 필요한 동작

다음 동작은 LLM이 곧장 실행하지 않고 사용자 확인을 받는다.

- 새 식물 생성
- 봉우리 포기(썩음 처리)
- 마감일 변경
- 식물 삭제

확인 응답은 "응/확인/네" 등 자유 발화로 받는다. 모호하면 다시 묻는다.
