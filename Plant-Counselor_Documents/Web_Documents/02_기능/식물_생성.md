# 식물 생성

> 식물은 사용자가 직접 만들지 않는다. 모든 생성은 LLM Skill을 통해서만.

관련 문서: [[LLM_흐름]], [[Skill_개요]], [[Plant]]

---

## 흐름

1. 사용자가 새 고민/일정을 발화.
2. LLM이 `match_plant` Skill로 기존 식물 매칭 시도.
3. 결과 분기:
   - 매칭됨 → 그 식물에 새 봉우리를 만들지 확인.
   - 없음 → 새 식물을 심을지 확인.
4. 사용자 동의 → `create_plant` Skill 즉시 호출.
5. 후속으로 `create_bud` Skill로 첫 봉우리 매달기.

---

## 입력 항목 (Skill 인자)

- `name`(분야명, 1~24자)
- `description`(한 줄 설명)
- `species`(외형 키, 기본 LLM 추정)
- `color`(컬러 토큰 키, species 기본 매핑)

---

## 중복 가드

- 같은 사용자 + 동일 활성 이름 식물 존재 시 Skill은 실패하고 `match_plant` 결과를 다시 안내.

---

## 삭제 / 아카이브

- 사용자가 명시적으로 발화한 경우에만 `delete_plant` Skill 호출.
- 활성 봉우리가 있으면 한 번 더 확인.
- 기본은 soft delete(`status='archived'`). 사용자가 명시하면 hard delete 가능.

---

## REST API와의 관계

- `POST /plants`는 의도적으로 제공하지 않는다. 생성/삭제는 Skill만.
- 식물 메타데이터 부분 수정은 `PATCH /plants/{id}`로 가능(이름·설명만).
