# 알림

> AI가 사용자에게 먼저 말을 거는 자발적 발화 + 백그라운드 트리거 큐.

관련 문서: [[홈]], [[상태_자동전이]], [[캘린더]], [[공통_AI대화창]], [[Skill_개요]], [[백그라운드_작업]]

---

## 알림 종류

| 종류 | 트리거 |
|---|---|
| `daily_briefing` | 접속 시 1회 |
| `wilting_warning` | 자동 전이로 wilting 진입 |
| `wilting_review` | wilting 추가 임계 초과 |
| `deadline_soon` | 마감일 임박 |
| `rot_disappeared` | rot 사라짐 직후 1회 |
| `idle_plant` | 활성 봉우리 0 식물에 장기간 손대지 않음 |

---

## 데이터

- `notifications` 테이블에 누적. 자세히는 [[DB_스키마#notifications]].
- API: `GET /notifications`, `POST /notifications/{id}/ack`.

---

## 표시

- 홈 진입 시 작은 토스트로 1~2개 노출.
- 우상단 종 아이콘 클릭 시 알림 센터 패널(전체 목록).
- 항목 클릭 → 해당 컨텍스트의 [[공통_AI대화창]] 열기.

---

## 푸시 / 이메일 (선택)

- 웹푸시(Service Worker + VAPID): 사용자 동의 시 활성화.
- 이메일: 마감 임박, 1주 이상 미접속 등 제한된 종류만.

---

## 사용자 설정 연동

- [[User#ai]].`proactive=false`이면 토스트 미노출(큐에는 쌓임).
- 임계값은 [[User#garden_rules]]에서 변경.
