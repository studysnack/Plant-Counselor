# 상태 관리

> 서버 상태는 **TanStack Query**, 클라이언트 UI 상태는 **Zustand**.

관련 문서: [[프론트엔드_구조]], [[API_클라이언트]], [[채팅_스트리밍]]

## 서버 상태 (TanStack Query)

### 쿼리 키 규칙

- 단일 자원: `["plant", plantId]`, `["bud", budId]`
- 컬렉션: `["plants"]`, `["buds"]`, `["buds", { plantId }]`
- 통계: `["stats"]`
- 대화: `["conversation", { scope, scopeId }]`

### Skill 실행 후 자동 무효화

`ChatPanel.tsx`의 `dirtySkills` + `SKILL_INVALIDATIONS` 맵이 관리:

```typescript
// onDone 콜백 내에서 실행
dirtySkills.current.forEach(skill => {
  (SKILL_INVALIDATIONS[skill] ?? []).forEach(key =>
    qc.invalidateQueries({ queryKey: [key[0]] })
  );
});
```

Skill별 무효화 대상:
- `create_plant` → `plants`, `stats`
- `delete_plant` → `plants`, `buds`, `stats`
- `create_bud` → `buds`, `plants`, `stats`
- `update_bud_status` → `buds`, `plants`, `stats`
- `update_bud_progress` → `buds`
- `harvest_bud` → `buds`, `plants`, `stats`
- `abandon_bud` → `buds`, `plants`, `stats`
- `set_deadline` → `buds`

## 클라이언트 상태 (Zustand)

### authStore

```typescript
accessToken: string | null
user: User | null
setSession(token, user)
clearSession()
```

`accessToken`은 **메모리에만**. 페이지 새로고침 시 `/auth/refresh` 호출로 복원.
복원 흐름: refresh 응답 → Zustand에 토큰 저장 → `/me` 호출 순서 중요.

### chatStore

```typescript
open: boolean
scope: { kind: string; id?: string }
open()
close()
setScope(scope)
```

CSS 변수 클래스를 `<html>`에 토글.

## SSE와의 결합

- `ChatPanel.tsx`의 `streamChat` 콜백이 SSE 토큰을 받아 메시지 상태를 누적 갱신.
- `onToolResult(name)` 콜백으로 `dirtySkills`에 Skill 이름 추가.
- `onDone` 콜백에서 `dirtySkills`를 기반으로 TanStack Query 캐시 무효화.
- 결과: AI가 식물/봉우리를 생성/수정하면 UI가 자동으로 최신 상태를 반영.
