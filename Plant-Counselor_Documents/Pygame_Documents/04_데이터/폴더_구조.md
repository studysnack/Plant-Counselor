# 폴더 구조

> 로컬 데이터 저장의 물리적 레이아웃.

관련 문서: [[User_JSON]], [[Plant_JSON]], [[Bud_JSON]], [[GardenState_JSON]], [[ConversationLog_JSON]], [[데이터_백업_복구]]

---

## 루트

설치 위치 아래 다음 구조가 만들어진다.

```
<앱 루트>/
├─ app/                       # 코드 (이 문서의 범위 외)
├─ assets/                    # 정적 자산 (이 폴더 안 세부 구조는 [[픽셀_에셋]], [[로고]] 참고)
│  ├─ pixels/                 # 잎/줄기/꽃/열매/화분/바닥/배경 (자세히는 [[픽셀_에셋]])
│  ├─ fonts/                  # 폰트 파일
│  ├─ logo/                   # 브랜드 로고 변형 (자세히는 [[로고]])
│  └─ icons/                  # UI 아이콘
└─ data/
   ├─ app.json                # 로그인 전 공용 설정(창 크기, 마지막 테마 미리보기, 언어 등)
   ├─ users/
   │  ├─ _last.json           # 최근 로그인 사용자 메모
   │  └─ <nickname>/          # 사용자별 정원
   │     ├─ user.json         # User_JSON (테마/AI/정원 규칙 등 사용자 설정)
   │     ├─ garden.json       # GardenState_JSON
   │     ├─ keys.bin          # API 키 저장(암호화 권장)
   │     ├─ plants/
   │     │  └─ <plant_id>/
   │     │     ├─ plant.json  # Plant_JSON
   │     │     └─ buds/
   │     │        └─ <bud_id>.json   # Bud_JSON
   │     ├─ conversations/
   │     │  ├─ global.json    # ConversationLog_JSON (scope=global)
   │     │  ├─ plant_<plant_id>.json
   │     │  └─ bud_<bud_id>.json
   │     ├─ snapshots/        # 자동 스냅샷
   │     ├─ archive/          # 삭제(아카이브)된 식물
   │     └─ quarantine/       # 손상 파일 격리
```

> 모든 사용자별 설정(테마, AI, 정원 규칙)은 [[User_JSON]]에 들어간다. `data/app.json`은 사용자 선택 화면에서만 필요한 공용 값(창 크기, 마지막 닉네임 힌트 등)만 보관한다. [[설정]] 페이지의 모든 설정은 사용자 단위다.

---

## 파일명 규칙

- `plant_id`, `bud_id`는 짧은 ULID 또는 UUIDv4 문자열.
- 사용자 폴더 이름은 닉네임. 파일 시스템에서 부적합한 문자는 치환.

---

## 동시 쓰기 보호

- 모든 JSON 쓰기는 [[클래스_함수_사전#FileStore]].`atomic_write`를 통해 임시 파일에 기록 후 원자적 교체.
- 한 사용자 세션은 단일 프로세스 가정. 다중 프로세스 동시 접근은 지원하지 않음.

---

## 경로 계산 책임

- 모든 경로는 [[클래스_함수_사전#PathResolver]]만 계산한다. 다른 코드는 직접 경로 문자열을 조합하지 않는다.
- 이를 통해 다른 사용자 폴더로의 우발적 접근을 막는다.
