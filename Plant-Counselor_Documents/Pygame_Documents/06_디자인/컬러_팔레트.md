# 컬러 팔레트

> Plant-Counselor 라이트 팔레트. 차분한 중립색 + 식물 그린 + 보조 포인트 색.
> 모든 컬러는 토큰 키로만 참조하고, 실제 16진수 값은 [[클래스_함수_사전#ThemeManager]]에 정의된다.

관련 문서: [[디자인_시스템]], [[그림자_효과]], [[로고]]

---

## 베이스 (중립)

| 토큰 키 | 이름 | HEX | 용도 |
|---|---|---|---|
| `bg.app` | 배경(Background) | `#F6F8F1` | 앱 전체 배경 |
| `bg.surface` | 표면(Surface) | `#FFFFFF` | 카드/패널 표면 |
| `bg.surface_soft` | 부드러운 표면(Surface Soft) | `#EEF4E9` | 보조 표면, 옅은 강조 패널, AI 메시지 풍선 |
| `border.subtle` | 테두리(Border) | `#D9E1D6` | 옅은 구분선/카드 테두리 |

---

## 텍스트

| 토큰 키 | 이름 | HEX | 용도 |
|---|---|---|---|
| `text.primary` | 본문 텍스트(Text) | `#18231D` | 본문/제목 |
| `text.muted` | 보조 텍스트(Muted) | `#667267` | 보조 설명/캡션 |
| `text.inverse` | — | `#FFFFFF` | 어두운 버튼/배지 위 텍스트 |

본문은 항상 `text.primary`, 부가 설명은 `text.muted`. `text.secondary` 같은 별도 단계는 두지 않는다(필요 시 `text.muted`로 통일).

## 브랜드 그린

| 토큰 키 | 이름 | HEX | 용도 |
|---|---|---|---|
| `brand.primary_leaf` | 메인 잎색(Primary Leaf) | `#4E7E4D` | 메인 액션, 사이드바 활성 아이콘, 진행 막대 |
| `brand.deep_stem` | 깊은 줄기색(Deep Stem) | `#223B2F` | 강한 강조, 헤더 텍스트, 픽셀 식물 줄기 |
| `brand.leaf_soft` | 부드러운 잎색(Leaf Soft) | `#CFE3C2` | 옅은 배경(아이콘 배지, 칩 selected soft) |
| `brand.mint_growth` | 성장 민트(Mint Growth) | `#9CCB8C` | 성장/꽃 단계 표시, 정상 상태 점, 진행률 강조 |

`brand.primary_leaf`가 가장 자주 쓰이는 메인 컬러. `brand.deep_stem`은 가장 진한 텍스트/그래픽에 한정.

## 식물 카테고리 → 액센트 매핑

각 [[Plant_JSON#color]]은 아래 토큰 키 중 하나를 가리킨다.

| 분야 예시 | 토큰 키 |
|---|---|
| 학업/업무 | `brand.primary_leaf` |
| 건강/수면 | `brand.mint_growth` |
| 일정/돈/진로 | `accent.amber_schedule` |
| 협업/AI 회고 | `accent.lavender_ai` |
| 관계/가족 | `accent.rose_care` |
| 취미/활력 | `accent.yellow_bloom` |

## "soft" 배경 규칙

각 액센트의 옅은 배경이 필요할 때는 별도의 `*_soft` 토큰을 두지 않고, 같은 색을 알파 0.18~0.22로 사용한다([[클래스_함수_사전#ThemeManager]].`color_alpha(key, alpha)`).
예외는 이미 별도 토큰으로 정의된 `brand.leaf_soft`와 `bg.surface_soft`.

---

## 사용 규칙

- 한 화면에 액센트는 동시에 3색 이하.
- 텍스트는 항상 `text.*` 토큰만 사용.
- 카드 기본 배경은 `bg.surface`, 보조 패널은 `bg.surface_soft`.
- 사이드바 배경도 `bg.surface_soft` 또는 동일 톤(별도 키를 추가하지 않음).
- 통계 카드 아이콘 배지: `brand.leaf_soft` 또는 액센트의 알파 배경.

---

## 다크/계절 변종

같은 토큰 키 집합에 대해 별도 값 묶음을 둔다.

- `light_default` (이 문서의 값)
- `light_summer`, `light_autumn`, `light_winter` — 베이스만 살짝 변동
- `night` — `bg.app`/`bg.surface`를 어둡게, 텍스트는 `text.inverse` 톤으로 재정의

전환: [[설정#4-시각사운드]] → [[클래스_함수_사전#ThemeManager]].`set_theme`.
