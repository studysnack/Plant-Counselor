# 식물 정원 레이아웃

> [[식물#식물-목록]] 화면. 식물들을 화분에 심어 한 줄로 늘어놓은 정원 풍경.

관련 문서: [[식물]], [[픽셀_에셋]], [[디자인_시스템]]

---

## 골격

```
+------+--------------------------------------------------+----------+
|      | [12개 식물] [시듦 3]                                |          |
|      |                                                    |          |
|  S   |                                                    |  Chat    |
|  i   |                                                    |  Panel   |
|  d   |     [식물1]   [식물2]   [식물3]   [식물4] ...        |          |
|  e   |                                                    |          |
|  b   |  ▓▓▓▓▓▓▓▓▓▓▓ 잔디 바닥 ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓        |          |
|  a   |     [라벨1]    [라벨2]    [라벨3]    [라벨4]         |          |
|  r   |                                                    |          |
|      |     [+] 추가                                        |          |
+------+--------------------------------------------------+----------+
```

---

## 배경

- 위쪽 큰 영역은 옅은 크림 `bg.app`.
- 아래쪽 약 1/3 지점부터 잔디 바닥 픽셀 패턴(`assets/pixels/floor/grass_*.png`)이 가로 반복으로 깔린다.
- 잔디 위에 작은 풀 더미 데코([[픽셀_에셋#장식-데코]])가 랜덤하게 배치.

---

## 식물 배치

- 화분 + 식물 일러스트가 가로로 일정 간격으로 정렬.
- 각 식물은 [[픽셀_에셋#식물-합성]] 규칙에 따라 합성된다(잎/줄기/꽃/열매 레이어).
- 식물 간 가로 간격은 화면 폭/식물 수에 따라 균등 분배(최소 `space.10`).
- 식물 아래에 라벨 카드(`bg.surface`, `radius.lg`, `shadow.md`)에 분야명·상태·"AI 상담방 열기" 버튼.

---

## 상단 메타 칩

- 좌상단: "12개 식물", "시듦 3" 같은 [[칩_뱃지#헤더-메타-뱃지]].
- 우측에는 정렬/필터 칩(옵션).

---

## 빈 정원

- 잔디 바닥은 유지하되 화분이 없는 상태.
- 가운데에 옅은 안내 카드: "어떤 분야의 식물을 먼저 키울까요?".

---

## 식물 라벨 카드

```
+------------------------+
| 발표 준비    [자라는 중] |
| AI 상담방 열기           |
+------------------------+
```

- 폭은 식물 폭의 1.5배.
- 상태 칩 색은 [[봉우리_생애주기#상태-목록]]에 맞춤.
- 버튼은 [[버튼]] secondary 변형.
