# 컴포넌트: 입력창

관련 문서: [[디자인_시스템]], [[상단바]], [[AI_채팅_패널]]

---

## 변형

| variant | 용도 |
|---|---|
| `text` | 일반 텍스트 |
| `search` | 좌측 돋보기 아이콘 |
| `chat` | 좌측 +(첨부), 우측 ↑(전송) |
| `password` | 비밀번호 마스킹 |

---

## 공통 스타일

- 높이 40~44px(크기에 따라).
- 배경 `bg.surface`, 테두리 `border.subtle`, 라운드 `radius.lg`.
- 내부 패딩 좌우 `space.4`.
- 포커스 시 테두리 `border.focus` + `shadow.sm`.
- placeholder 색 `text.muted`.

---

## 검색 입력창

- 좌측 아이콘 16×16, 텍스트와 사이 `space.2`.
- 입력 중 우측에 작은 X(클리어).

---

## 채팅 입력창

- 좌측 + 버튼은 [[버튼#아이콘-버튼]] ghost 변형.
- 우측 ↑ 버튼은 `primary` 작은 원형.
- 입력 길이가 늘면 멀티라인으로 부드럽게 확장(최대 5줄).
