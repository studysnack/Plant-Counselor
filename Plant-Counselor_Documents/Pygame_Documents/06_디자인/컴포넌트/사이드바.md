# 컴포넌트: 사이드바

관련 문서: [[디자인_시스템]], [[간격_레이아웃]], [[UI_구조]]

---

## 구조

```
+--------+
|  로고  |   ← 24x24 아이콘 + "Plant" 텍스트(작게)
+--------+
|   홈   |   ← 아이콘 버튼 40x40
|  식물  |
| 캘린더 |
|  채팅  |
|  설정  |
+--------+
|  +    |   ← 좌하 절대 위치(빠른 추가)
+--------+
```

폭 **72px** 고정. 배경 `bg.surface_soft`. 우측 1px `border.subtle`.

---

## 아이콘 항목

- 크기 40×40, 라운드 `radius.md`, 아이콘 자체 24×24.
- 상태:
  - default: 투명 배경, 아이콘 `text.muted`
  - hover: 배경 `brand.leaf_soft`
  - active(현재 화면): 배경 `brand.primary_leaf`, 아이콘 `text.inverse`
  - focused: `border.focus`
- 아이콘 사이 간격 `space.3` (12px).

---

## 좌하단 + 버튼

- 원형(`radius.pill`), 40×40.
- 클릭 시 [[공통_AI대화창]]을 빠른 입력 모드로 연다(빈 정원에선 식물 생성 흐름).
