# 컴포넌트: 캘린더 패널

> 홈 우측 영역의 캘린더 + 시간대별 일정 리스트.

관련 문서: [[홈]], [[캘린더]], [[디자인_시스템]]

---

## 구조

```
캘린더 AI
고민 상태와 일정 우선순위를 함께 조정합니다

[월][화][수][목][금][토][일]    ← 요일 헤더(text.caption)
[15][16][17][18][19][20][21]   ← 일자(text.h2). 오늘은 진한 배경 pill

---------- 일정 라인 ----------
| 컬러 바 | 10:00 | 업무 식물            |
|          |       | 고민 원인 검토        |

| 컬러 바 | 15:30 | 학습 식물            |
|          |       | 작업을 두 단계로 나누기 |

| 컬러 바 | 20:00 | AI 회고              |
|          |       | 오늘의 성장 요약      |
```

- 외곽 카드: `bg.surface`, `radius.xl`, `shadow.md`, 패딩 `space.6`.

---

## 요일 / 일자 행

- 요일 라벨: `text.caption`, `text.muted`.
- 일자: `text.h2`, 가운데 정렬.
- 오늘 일자: pill 배경 `brand.primary_leaf`, 글자 `text.inverse`.

---

## 일정 라인

- 좌측 4px 두께의 컬러 바(식물 액센트 색).
- 시간(`text.mono`), 식물명(`text.h2`), 짧은 액션 설명(`text.body_sm`).
- 라인 사이 간격 `space.4`.
- 라인 클릭 → 해당 봉우리 상세로 이동.
