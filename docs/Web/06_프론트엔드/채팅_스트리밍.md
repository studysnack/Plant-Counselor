# 채팅 스트리밍

> 최종 점검: 2026-06-02

`POST /api/v1/chat/message`는 SSE 스트림을 반환한다. 프론트는 POST를 지원하지 않는
`EventSource` 대신 `fetch`와 `ReadableStream`을 사용한다.

## 이벤트

| event | 의미 |
| --- | --- |
| `start` | assistant message ID |
| `tool_call` | AI 스킬 호출 시작 |
| `tool_result` | 스킬 실행 결과 |
| `token` | 부분 텍스트 |
| `error` | 처리 오류 |
| `done` | 스트림 종료 |

프론트 `streamChat()`은 서버가 `done` 없이 연결을 닫아도 마지막에 완료 콜백을 한 번
호출해 로딩 상태를 정리한다.

SSE 프레임 형식:

```text
event: token
data: {"text":"..."}

```

## 요청

```typescript
{
  text: string
  scope?: "global" | "plant" | "bud" | "calendar"
  scope_id?: string
  current_screen?: string
}
```

## 캐시 반영

`ChatPanel.tsx`는 `tool_result`를 수집하고 종료 시 관련 TanStack Query 캐시를
무효화한다. 식물, 봉우리, 통계, 캘린더 변경이 화면에 즉시 반영되는 경로다.

스트림 요청도 `Authorization: Bearer ...` 헤더를 사용한다.
