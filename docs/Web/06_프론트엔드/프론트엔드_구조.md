## 폴더 트리

```
frontend/
├─ app/
│  ├─ layout.tsx                  # 루트 레이아웃(Providers)
│  ├─ globals.css                 # Tailwind v4 + CSS 변수(토큰)
│  ├─ proxy.ts                    # API 프록시 (Next.js 16: middleware.ts 아님)
│  ├─ (auth)/
│  │  ├─ login/page.tsx
│  │  └─ signup/page.tsx
│  └─ (app)/                      # 인증 필요 그룹
│     ├─ layout.tsx               # 인증 복원 + 사이드바 + 상단바 + ChatPanel 호스트
│     ├─ page.tsx                 # 홈
│     ├─ plants/
│     │  ├─ page.tsx              # 식물 목록
│     │  └─ [id]/page.tsx         # 식물 상세
│     └─ settings/page.tsx
├─ components/
│  ├─ chat/
│  │  └─ ChatPanel.tsx            # SSE 스트리밍 + Skill 캐시 무효화
│  ├─ home/
│  ├─ plants/
│  ├─ ui/
│  └─ layout/
│     ├─ Sidebar.tsx
│     └─ TopBar.tsx
├─ lib/
│  ├─ api/
│  │  └─ client.ts               # fetch 래퍼(인증/오류/리프레시) + streamChat
│  ├─ store/
│  │  ├─ authStore.ts            # Zustand: accessToken(메모리), user
│  │  └─ chatStore.ts            # 열림 상태, 현재 스코프
│  └─ hooks/
├─ public/assets/
├─ tailwind.config.ts
├─ tsconfig.json
└─ package.json
```

---

## 라우팅

- App Router 사용. `(auth)`, `(app)` 그룹으로 레이아웃 분리.
- `proxy.ts`가 `/api/*` 요청을 백엔드로 프록시.
- **Note**: Next.js 16에서 API 프록시는 `middleware.ts`가 아닌 `proxy.ts`를 사용 (Next.js 16 breaking change).

---

## 핵심 Provider

- `app/layout.tsx`:
  - `QueryClientProvider` (TanStack Query)
  - CSS 변수 테마 토큰
- `(app)/layout.tsx`:
  - 인증 복원 (`restore()` — refresh → Zustand 저장 → /me)
  - 사이드바/상단바 고정 + 본문 outlet
  - `ChatPanel` 항상 마운트 (열림 상태는 `chatStore`)

## 페이지 ↔ 컴포넌트 매핑

| 페이지 | 주요 컴포넌트 |
|---|---|
| `/` (홈) | SummaryCards, PlantBoard, WiltingSection |
| `/plants` | 식물 카드 그리드 (→ 계획: GardenLayout + GrassFloor + PlantSprite) |
| `/plants/[id]` | PlantHeader, PlantStage, BudWidget, BudDetailPanel |
| `/settings` | 계정/AI/정원 설정 폼 |
| `(공용)` | Sidebar, TopBar, ChatPanel |

## CSS 토큰 시스템

- `globals.css`에 CSS 변수로 정의: `--bg-surface`, `--text-primary`, `--brand-leaf`, `--border-subtle` 등.
- 라이트/다크 테마는 `:root` vs `.dark` 클래스로 토글.
- 컴포넌트에서 `style={{ background: "var(--bg-surface)" }}` 형태로 직접 사용.
- Tailwind v4는 CSS 변수 기반 테마 설정 방식 사용.

## SSR 정책

- 인증 페이지는 클라이언트 렌더 (보호 데이터 SSR 누출 방지).
- 비인증 페이지(`/login`, `/signup`)는 SSR 허용.
