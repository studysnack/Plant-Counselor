# 상태 관리

> 최종 점검: 2026-06-02

서버 상태는 TanStack Query, 클라이언트 UI 상태는 Zustand로 관리한다.

## Query key

새 코드는 `frontend/lib/queryKeys.ts`의 `QK` 팩토리를 사용한다.

```typescript
QK.plants()
QK.plant(id)
QK.buds()
QK.plantBuds(plantId)
QK.bud(id)
QK.summary()
QK.briefing()
QK.calendar(year, month)
QK.notifications()
QK.conversations()
```

같은 데이터를 임의 배열로 다시 정의하면 페이지 이동 시 캐시가 재사용되지 않는다.

## Zustand store

| store | 역할 |
| --- | --- |
| `authStore.ts` | access token과 백엔드 프로필 |
| `chatStore.ts` | 패널 열림, 스코프, 너비, 세션 이관 |
| `themeStore.ts` | light, dark, system 모드와 해석된 모드 |

`authStore`는 프로필만 persist한다. access token은 Supabase 세션에서 mount마다
복원하고 `onAuthStateChange`로 동기화한다.

## 채팅 mutation

`ChatPanel.tsx`는 스킬 실행 결과에 따라 관련 query key를 무효화한다. 변이 스킬을
추가하거나 제거할 때 `SKILL_INVALIDATIONS`를 함께 수정한다.

주요 mutation 영향:

| 스킬 | 무효화 범위 |
| --- | --- |
| `create_plant`, `delete_plant` | 식물, 봉우리, 통계, 브리핑 |
| `create_bud` | 봉우리, 식물, 통계, 브리핑, 캘린더 |
| `update_bud_status`, `harvest_bud`, `abandon_bud` | 봉우리, 식물, 통계, 브리핑 |
| `set_deadline` | 봉우리, 캘린더, 통계 |
| 캘린더 일정 생성, 수정, 삭제 | 캘린더 |
