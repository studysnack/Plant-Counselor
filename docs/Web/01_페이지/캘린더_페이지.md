# 캘린더 페이지 (라우트: `/calendar`)

> 캘린더 + 오늘 일정 + AI 일정 제안 + 일정 상태 요약을 한 화면에 모은 독립 페이지.

관련 문서: [[Web/02_기능/캘린더]] (홈 패널 버전), [[Web/01_페이지/홈]], [[Web/01_페이지/공통_AI대화창]]

---

## 라우트

- `app/(app)/calendar/page.tsx`
- 인증 필요.

---

## 데이터 페치

| 영역 | API | 쿼리 키 |
|---|---|---|
| 월 그리드 | `GET /calendar?from=YYYY-MM-01&to=YYYY-MM-31` | `["calendar", year, month]` |
| 오늘 일정 | `GET /buds?deadline_within_days=1` 또는 `GET /calendar?from=today&to=today` | `["calendar", "today"]` |
| AI 일정 제안 | `GET /briefing/today` (재사용) 또는 별도 endpoint | `["briefing", "today"]` |
| 일정 상태 요약 | `GET /stats/full?period=this_week` | `["stats", "calendar_summary"]` |

---

## 페이지 영역

1. 헤더(타이틀 + 검색)
2. 메인 캘린더 카드 (`CalendarMonthGrid`)
3. 우측 사이드: 오늘 일정 카드 + AI 일정 제안 카드
4. 하단: 일정 상태 요약 카드

사이드바와 ChatPanel은 `(app)` 레이아웃이 제공.

---

## 사이드바 활성 상태

- 사이드바 3번째 아이콘(캘린더)이 active.

---

## 인터랙션

- 캘린더 셀 클릭 → 해당 날짜 봉우리 리스트 팝오버.
- "이번 달" 버튼 좌우 화살표 → 월 이동(쿼리 파라미터 `?ym=2026-05` 동기화).
- 오늘 일정/AI 제안 라인 클릭 → 해당 봉우리 상세(`/plants/[id]`로 이동).
- 하단 요약 카드 클릭 → 필터 적용된 봉우리 목록으로 이동.
