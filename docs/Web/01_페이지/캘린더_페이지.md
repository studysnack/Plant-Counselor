# 캘린더 페이지

> 라우트: `/calendar`

## 데이터

| 영역 | API | Query key |
| --- | --- | --- |
| 월간 일정 | `GET /api/v1/calendar?from=...&to=...` | `QK.calendar(year, month)` |
| 브리핑 | `GET /api/v1/briefing/today` | `QK.briefing()` |
| 상태 요약 | `GET /api/v1/stats/summary` | `QK.summary()` |
| 식물 선택 | `GET /api/v1/plants` | `QK.plants()` |

## 레이아웃

- 월간 달력 카드
- 달력과 같은 높이의 오른쪽 열: 선택 날짜 일정, AI 일정 제안, 일정 추가 버튼
- 하단 일정 상태 요약 카드 4개

달력 아래에 선택 날짜 일정을 길게 반복 표시하지 않는다. 선택 날짜 일정이 많으면 카드
전체가 늘어나는 대신 목록 내부에서 스크롤한다.

캘린더는 `frontend/app/globals.css`의 `.calendar-layout`을 사용한다. 데스크톱에서는
월간 달력과 오른쪽 열을 2단으로 배치하고, 행 높이는 `clamp(440px, 52vh, 560px)`로
잡는다. 좁은 화면에서는 오른쪽 열이 달력 아래로 내려간다.

## 인터랙션

- 이전 달, 오늘, 다음 달 이동
- 날짜 선택 후 오른쪽 열에서 해당 날짜 일정 조회
- 독립 일정 추가, 수정 modal: 관련 식물, 상세 정보, 6개 팔레트 색상 선택
- 독립 일정 삭제
- 봉우리 일정 클릭: 해당 식물 상세의 봉우리 drawer로 이동
- 선택 날짜 일정 물어보기: calendar 스코프 AI 패널을 열고 실제 질문 전송
