# 홈 페이지

> 라우트: `/home`

로그인 직후 진입하는 요약 대시보드다.

## 데이터

| 데이터 | API | Query key |
| --- | --- | --- |
| 요약 통계 | `GET /api/v1/stats/summary` | `QK.summary()` |
| 브리핑 | `GET /api/v1/briefing/today` | `QK.briefing()` |
| 식물 | `GET /api/v1/plants` | `QK.plants()` |
| 봉우리 | `GET /api/v1/buds` | `QK.buds()` |

## 구성

- 상단 브리핑
- 진행 중 일정, 진행 중 고민, 주의 필요, 이번 달 수확 통계
- 식물 카드 목록과 새 식물 CTA
- 시들고 있는 봉우리 목록

식물 카드와 시듦 목록의 상담 버튼은 해당 맥락으로 AI 패널을 연다. 빈 정원에서는
새 식물 CTA가 global 채팅을 열어 첫 분야 생성을 유도한다.
