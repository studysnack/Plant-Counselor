## 라우트

- Next.js App Router: `app/(app)/page.tsx`
- 인증 필요. 미인증 시 `/login`으로 리다이렉트.

---

## 데이터 페치

| 데이터 | API | 쿼리 키 |
|---|---|---|
| 요약 통계 | `GET /stats/summary` | `["stats"]` |
| 식물 목록 | `GET /plants` | `["plants"]` |
| 봉우리 목록 | `GET /buds` | `["buds"]` |

페치는 TanStack Query로. Skill 실행 후 자동 무효화.

---

## 섹션 구성

1. **상단 요약 카드** — 활성 고민 수, 일정 수, 수확 수, 시드는 봉우리 수.
2. **식물 관리 보드** — 식물 카드 그리드 (→ 계획: 정원 풍경 뷰로 전환).
3. **시들고 있는 봉우리** — 시듦 상태 봉우리 목록.

---

## 빈 정원

- 식물이 0개일 때 안내 카드 + AI 대화 유도.
- AI가 `create_plant` 흐름으로 첫 식물 생성을 안내.
