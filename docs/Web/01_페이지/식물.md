## 라우트

- `app/(app)/plants/page.tsx` — 식물 목록(정원 풍경)
- `app/(app)/plants/[id]/page.tsx` — 식물 상세

---

## 식물 목록 — 현재 상태

- 카드 그리드 형태로 식물을 표시.
- 각 카드에 식물명, 봉우리 수, 상태 배지 표시.
- 빈 정원: AI가 첫 식물 생성 대화 유도.
- 데이터: `GET /plants`.

## 식물 목록 — 계획 (정원 뷰)

- **잔디 바닥 위에 픽셀 식물이 심어진 정원 풍경**으로 전환.
- 카드 그리드 → 토지에 실제로 자라는 식물 애니메이션.
- `PlantSprite` 컴포넌트: 종·상태·진행률 props로 픽셀 레이어 합성.
- CSS `image-rendering: pixelated`로 nearest-neighbor 보장.
- 자세한 사항: [[개선사항]]

---

## 식물 상세

- 데이터: `GET /plants/{id}` + `GET /buds?plant_id={id}`.
- 영역 구성:
  - `PlantHeader` — 분야명, 설명, 누적 통계.
  - `PlantStage` — 식물과 봉우리 시각화.
  - `BudDetailPanel` — 봉우리 클릭 시 상세 패널.

### 봉우리 시각화

- 상태에 따라 모양이 다른 노드(`BudWidget`).
- 호버 시 제목 미리보기 툴팁.
- 클릭 시 상세 패널에 제목/설명/타입/상태/진행률/마감일/이력 표시.

### 식물 상세에서의 AI 대화 (계획)

- 식물 상세 페이지에서 채팅 열기 시 해당 식물로 줌인 + plant 스코프 대화 세션 활성화.
- 자세한 사항: [[개선사항]]

---

## 액션은 모두 대화로

- "이 봉우리 꽃 피웠어" → `update_bud_status`
- "포기할래" → `abandon_bud`
- "마감일 다음 주 금요일로 바꿔줘" → `set_deadline`
- "끝났어" → `harvest_bud`
