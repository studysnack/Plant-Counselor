# 식물 페이지

> 라우트: `/plants`, `/plants/[id]`

## 정원과 리스트

`/plants`는 정원, 리스트 전환 HUD를 제공한다.

- 정원 뷰는 넓은 잔디 위에 픽셀 식물을 배치한다.
- 봉우리 하나당 `64px` 성장 레이어가 위로 추가된다.
- 봉우리가 하나도 없는 식물은 대체 새싹 없이 화분만 표시한다.
- 식물이 길어져도 화분과 땅 기준선은 고정하고 하늘 영역이 늘어난다.
- 수확된 봉우리는 새싹 형태로 남는다.
- 썩어 사라진 봉우리는 해당 성장 레이어도 제거된다.
- 식물이 많아지면 정원 폭이 오른쪽으로 늘어나고 가로 스크롤로 확인한다.
- 빈 자리를 누르면 AI 채팅 패널을 열어 새 식물 생성을 유도한다.
- 우측 하단 HUD의 `-`, 배율, `+` 버튼으로 정원을 `50%`부터 `200%`까지 확대하거나
  축소한다. 가운데 배율 버튼은 `100%`로 초기화한다.
- 트랙패드 pinch 제스처로도 정원을 연속 확대하거나 축소한다. 축소된 잔디 보드가
  현재 화면보다 작아지지 않게 논리 크기를 보정해 빈 정원에서도 배경이 끊기지 않는다.
- 봉우리 위에 마우스를 올리면 해당 봉우리 이름을 툴팁으로 표시한다.
- 정원 픽셀의 특정 봉우리를 클릭하면 `/plants/{plantId}?bud={budId}`로 이동하고,
  해당 식물 상세 화면에서 선택한 봉우리 drawer를 즉시 연다.
- 상태별 픽셀은 Figma `05 Plant Pixel Assets`의 no-pot extension 좌표를 따른다.
  잎 방향을 레이어별로 임의 반전하지 않으며, 시듦은 갈변한 굽은 상단 조각, 썩음은
  초록 줄기 위 상한 열매로 표시한다.

실제 픽셀 식물과 정보 카드는
`frontend/components/plants/GardenPlantVisual.tsx`에서 합성한다. 로그인 전 랜딩
`#preview`의 예시도 같은 컴포넌트를 사용한다.

## 식물 상세

`/plants/[id]`는 식물 정보와 봉우리 목록을 표시한다. 봉우리를 선택하면 상세 drawer에서
상태, 진행률, 마감일, 이력을 확인하고 수정할 수 있다.

상세와 정원 카드의 상담 버튼은 해당 식물 또는 봉우리 스코프로 AI 패널을 연다.
직접 URL로 다른 사용자의 식물을 요청하면 백엔드 `user_id` 필터로 조회되지 않는다.

## API

- `GET /api/v1/plants`
- `GET /api/v1/plants/{id}`
- `GET /api/v1/buds?plant_id={id}`
