## 라우트

- `app/(app)/settings/page.tsx` — 단일 페이지 내부에서 탭(`?tab=...`) 전환.

## 탭

1. **계정** — 닉네임, 이메일, 비밀번호 변경, 데이터 내보내기/가져오기, 계정 삭제.
2. **AI** — Gemini API 키 입력(향후 사용자별 키), 톤, 호칭, 자발 발화 on/off.
3. **정원 규칙** — 시듦/썩음/마감 임계값, 자동 전이 사용 여부.
4. **시각/사운드** — 테마(시즌/야간/자동), 애니메이션 강도, 효과음/BGM/볼륨.
5. **데이터** — 스냅샷 목록, 무결성 검사, 대화 로그 삭제.
6. **정보** — 버전, 라이선스, 도움말 링크.

각 탭의 변경은 `PATCH /me`로 부분 갱신. API 키는 `PUT /me/api-key`.

---

## 보안 동작

- 비밀번호 변경: 현재 비번 확인 → 새 비번 2회 입력. 성공 시 다른 디바이스의 모든 refresh 토큰 무효화 옵션 표시.
- 계정 삭제: 닉네임 재입력 확인 모달.
- API 키: 마스킹 표시, 저장 후 평문은 다시 반환하지 않음.
