# 설정 페이지

> 라우트: `/settings`

설정 화면은 5개 탭을 제공한다.

| 탭 | 기능 |
| --- | --- |
| 계정 | Google 프로필 표시, 로그아웃, 계정과 데이터 영구 삭제 |
| AI | 사용자별 Gemini API 키 저장, 응답 톤 설정 |
| 정원 규칙 | 시듦, 썩음, 마감 경고 기준 변경 |
| 테마 | light, dark, system 모드 |
| 정보 | 서비스 정보 |

프로필과 정원 규칙은 `PATCH /api/v1/me`, API 키는 `PUT /api/v1/me/api-key`, 계정
삭제는 `DELETE /api/v1/me`를 사용한다.

별도 강조색 선택, 비밀번호 변경, 데이터 내보내기, 사운드 설정 UI는 현재 페이지에
없다.

## 보안 동작

- 사용자 API 키는 `PUT /api/v1/me/api-key`로 전송하고 평문을 다시 표시하지 않는다.
- 계정 삭제는 현재 이메일을 다시 입력해야 실행된다.
- 삭제 성공 뒤 Supabase 로그아웃과 Query cache 초기화를 수행한다.
