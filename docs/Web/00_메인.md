# Plant Counselor (Web) — 메인 문서

> 나의 계획, 고민, 일정 등을 식물로 시각화하는 LLM 기반 웹 애플리케이션.
> 본 문서는 전체 구조의 색인이며, 세부는 각 하위 문서에 분리되어 있다.

---

## 한눈에 보기

- 사용자의 **고민/일정**을 LLM과의 대화만으로 입력/관리한다.
- 모든 항목은 **식물(분야) → 봉우리(개별 항목)** 메타포로 시각화된다.
- 봉우리는 **씨앗 → 봉우리 → 꽃 → 열매 → 수확**의 생애주기를 가지며, 정체되면 **시듦**, 포기되면 **썩음**으로 이동한다.
- LLM은 [[Web/03_LLM/Skill_개요]]에 정의된 **Skill 집합**을 통해 백엔드 데이터를 조작한다.
- **"AI로 모든 서비스에 접근할 수 있다"** — 모든 데이터 조작은 대화 하나로 가능하다.

---

## 기술 스택

| 레이어 | 선택 | 비고 |
|---|---|---|
| 백엔드 | **FastAPI** (Python 3.11+) | 비동기, OpenAPI 자동 생성 |
| ORM / DB | **SQLAlchemy 2.x + SQLite**(개발) / **PostgreSQL**(운영) | 사용자별 데이터 격리 |
| 인증 | **JWT(액세스) + HttpOnly Refresh Cookie** | 액세스 토큰은 메모리(Zustand)만 |
| LLM | **Google Gemini** (`gemini-2.5-flash`, `google-genai` SDK) | Skill은 Gemini function-calling 형식으로 변환 |
| 백그라운드 | **APScheduler** (in-process) | 시듦/마감 알림의 주기 검사 |
| 프론트엔드 | **Next.js 16 (App Router) + TypeScript** | `proxy.ts`로 API 프록시 |
| 상태관리 | **TanStack Query**(서버 상태) + **Zustand**(클라 상태) | Skill 실행 후 자동 캐시 무효화 |
| 스타일 | **Tailwind CSS v4** + CSS 변수(테마 토큰) | `globals.css`에 토큰 정의 |
| 패키지 매니저 | 백엔드 `uv`, 프론트 `pnpm` | |
| 채팅 로그 | **LogRecorder** | 턴당 JSON 파일로 전체 컨텍스트 저장 |

|---|---|
| 정원(Garden) | 사용자 1명의 전체 공간 |
| 식물(Plant) | 분야(카테고리) |
| 봉우리(Bud) | 개별 고민/일정 |
| 꽃(Flower) | 활발히 진행 중 |
| 열매(Fruit) | 마무리 직전 |
| 수확(Harvest) | 완료 |
| 시듦(Wilting) | 정체 상태 |
| 썩음(Rot) | 포기됨 |

## Pygame 버전과의 차이

- 데이터 저장: 로컬 JSON 파일 트리 → **서버 RDB**(사용자별 행 격리).
- UI: pygame Scene/위젯 → **React 컴포넌트 + Next.js 페이지**.
- 테마/토큰: ThemeManager → **CSS 변수 + Tailwind**.
- 상태 자동 전이: 앱 부팅 시 + 주기 → **백그라운드 스케줄러**.
- 알림: 인앱 토스트 + 선택적으로 웹 알림 추가 가능.
- 회원가입/로그인: 닉네임 파일 시스템 → **이메일/비밀번호 + JWT**.
- LLM: pygame 버전과 달리 사용자가 API 키 없이 서버 Gemini 키로 이용.
