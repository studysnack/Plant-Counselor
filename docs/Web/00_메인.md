# Plant Counselor 웹 문서

> 최종 점검: 2026-06-04

Plant Counselor는 고민, 목표, 일정을 식물 생애주기로 표현하는 AI 정원사 웹
서비스다. 현재 코드와 충돌하면 루트 `AGENTS.md`와 실제 코드를 우선한다.

## 한눈에 보기

- 식물은 관리 분야 또는 카테고리다.
- 봉우리는 고민, 목표, 추적할 일정이며 진행률과 생애주기를 가진다.
- 일반 일정은 약속, 예약, 리마인더이며 캘린더에 별도로 저장한다.
- AI 정원사는 Gemini ReAct 루프에서 20개 스킬을 연속 호출한다.
- 응답은 SSE로 스트리밍한다.
- 정원은 Figma 픽셀 에셋 기반 성장 레이어를 위로 쌓고, 50%~200% 확대·축소로
  무한 성장을 탐색한다.
- 주요 사용자 화면은 공통 반응형 레이아웃 규칙으로 큰 화면과 좁은 화면을 함께
  대응한다.

## 핵심 메타포

| 요소 | 의미 |
| --- | --- |
| 정원 | 사용자의 전체 관리 공간 |
| 식물 | 관리 분야 또는 카테고리 |
| 봉우리 | 고민, 목표, 추적 일정 |
| 일반 일정 | 진행률이 필요 없는 약속, 예약, 리마인더 |
| 수확 | 완료 |
| 시듦 | 활동이 오래 없는 상태 |
| 썩음 | 포기 또는 장기 방치 |

## 기술 스택

| 계층 | 현재 구현 |
| --- | --- |
| Frontend | Next.js 16.2.6, React 19.2.4, TypeScript, Tailwind CSS v4 |
| State | TanStack Query v5, Zustand |
| Backend | FastAPI, Pydantic v2, APScheduler |
| DB access | `supabase-py` PostgREST HTTP |
| Database | Supabase PostgreSQL |
| Auth | Supabase Auth Google OAuth, Bearer JWT, ES256 JWKS 검증 |
| LLM | Google Gemini via `google-genai` |

SQLAlchemy, SQLite, 커스텀 이메일/비밀번호 인증, refresh 쿠키는 현재 웹 구현에
사용하지 않는다.
