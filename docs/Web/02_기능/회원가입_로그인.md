# 회원가입 / 로그인

관련 문서: [[인증_세션]], [[API_엔드포인트]], [[User]], [[Web/01_페이지/설정]]

---

## 첫 진입

- 비로그인 사용자가 보호 경로에 접근하면 `(app)/layout.tsx`의 복원 로직이 실패 시 `/login`으로 리다이렉트.

---

## 회원가입 (`/signup`)

1. 이메일, 닉네임(2~16자), 비밀번호(8자 이상 + 2회 확인).
2. 약관 동의 체크.
3. `POST /auth/signup`.
4. 성공 시 자동 로그인하지 않고 로그인 화면으로 안내(이메일 확인 단계 도입 시 자연스러움).

---

## 로그인 (`/login`)

1. 이메일/비밀번호.
2. `POST /auth/login` → 액세스 토큰(메모리/Zustand) + Refresh 쿠키.
3. 성공 시 `/`로 이동.
4. 실패 5회 시 일정 시간 입력 차단(IP + 이메일 단위).

---

## 자동 갱신

- 액세스 토큰 만료 시 fetch 래퍼가 `POST /auth/refresh`를 호출해 새 액세스 토큰 획득 후 원래 요청 재시도.
- 모든 라우터 컴포넌트에서는 인증 실패가 자연스럽게 로그인 화면 리다이렉트로 이어진다.

---

## 로그아웃

- [[Web/01_페이지/설정#계정]] 또는 사이드바 메뉴에서 트리거.
- `POST /auth/logout` → 리프레시 쿠키 폐기 + 메모리 토큰 클리어 → `/login`으로 이동.

---

## 계정 삭제

- [[Web/01_페이지/설정]]의 "계정 삭제" → 닉네임 재입력 모달 → `DELETE /me`.
- 서버는 사용자와 관련 데이터 모두 hard delete. 백업 zip 권장 안내.

---

## 비밀번호 정책

- 최소 8자, 권장 12자.
- argon2id 해시.
- 변경 시 [[인증_세션#비밀번호-정책]]에 따른 후속 처리.
