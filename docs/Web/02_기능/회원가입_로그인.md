# 로그인

> 최종 점검: 2026-06-02

관련 문서: [[인증_세션]], [[API_엔드포인트]], [[Web/01_페이지/설정]]

## 첫 진입

- 비로그인 사용자가 보호 경로에 접근하면 `(app)/layout.tsx`가 `/login`으로
  리다이렉트한다.
- 별도 회원가입 페이지는 없다.

## Google 로그인

1. `/login`에서 Google 로그인을 시작한다.
2. Supabase Auth가 OAuth 콜백을 처리한다.
3. `@supabase/supabase-js`가 브라우저 localStorage에 세션을 저장한다.
4. 앱 레이아웃이 access token을 Zustand와 API 클라이언트에 연결한다.
5. `GET /api/v1/me`로 프로필을 조회한다. 처음 로그인한 사용자는 백엔드가 프로필을
   자동 생성한다.
6. 프론트는 Supabase 세션의 `user_metadata.avatar_url` 또는 `picture`를 프로필
   상태에 병합해 사이드바에 Google 프로필 사진을 표시한다.
7. 일반 사용자는 `/home`, 관리자는 `/admin`으로 이동한다.

## 자동 갱신

Supabase 클라이언트가 세션을 자동 갱신하고 `onAuthStateChange`로 새 토큰을 전달한다.
일반 API가 401을 반환하면 API 클라이언트가 `supabase.auth.refreshSession()`을 한 번
시도한다.

## 로그아웃과 계정 삭제

- 로그아웃: 설정 화면에서 `supabase.auth.signOut()`을 호출한다.
- 계정 삭제: 설정 화면에서 이메일을 다시 입력한 뒤 `DELETE /api/v1/me`를 호출한다.

커스텀 이메일/비밀번호 인증, refresh 쿠키, `/auth/*` API는 현재 코드에 없다.
