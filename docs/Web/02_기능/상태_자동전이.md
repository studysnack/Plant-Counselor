# 상태 자동 전이

`TransitionService.scan_all()`이 모든 프로필의 정원 규칙을 읽고 시간 기반 전이와
마감 알림을 처리한다.

## 실행

- APScheduler `transition_scan`
- 기본 10분 주기
- 관리자 수동 실행: `POST /api/v1/admin/controller/scheduler/trigger`

## 처리

1. 활성 봉우리 `bud`, `flower`, `fruit`가 오래 갱신되지 않으면 `wilting`.
2. `wilting` 상태가 더 오래 유지되면 `rot`로 바꾸고 `disappeared_at` 기록.
3. 마감 임박 봉우리에 `deadline_warning` 알림 생성.
4. 같은 봉우리의 미확인 마감 알림이 있으면 중복 생성하지 않음.

## 기본 규칙

```text
wilting_days = 7
rot_disappear_days = 14
deadline_warn_days = 3
auto_transition = true
```

시간은 `runtime_settings.py`의 `rs.now()`와 `rs.today()`를 사용해 UTC+9 기본 타임존과
관리자 타임 트래블을 반영한다.
