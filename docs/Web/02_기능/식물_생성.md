# 식물 생성

식물 생성은 AI 스킬을 통해 수행한다. `/plants` 정원의 빈 자리나 홈의 새 식물 CTA는
global 채팅 패널을 연다.

## 흐름

1. 사용자가 관리할 분야나 고민을 말한다.
2. AI가 `match_plant`로 기존 식물을 탐색한다.
3. 기존 분야가 적합하면 해당 식물에 `create_bud`.
4. 새 분야가 필요하면 `create_plant`, 이어서 필요에 따라 `create_bud`.

의도가 충분하면 확인 질문 없이 즉시 실행한다. 식물 생성용 REST `POST /plants`는
제공하지 않는다.

식물 수정은 `PATCH /api/v1/plants/{id}`, 삭제는 AI `delete_plant` 스킬 또는
`DELETE /api/v1/plants/{id}`를 사용한다.

## 입력과 삭제

- `name`: 분야명
- `description`: 분야 설명
- `species`: 외형 키
- `color`: 색상 키

`match_plant`는 같은 사용자 안에서 유사 이름을 먼저 탐색한다. 삭제 REST API의 기본
동작은 archive이고, `hard=true`일 때만 hard delete한다.
