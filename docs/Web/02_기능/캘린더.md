# 캘린더

캘린더는 봉우리 마감일과 진행률 없는 독립 일정을 한 화면에 병합한다.

| 종류 | 저장 위치 | 응답 source |
| --- | --- | --- |
| 추적 일정 | `buds.deadline` | `bud` |
| 독립 일정 | `calendar_events` | `event` |

## API

- `GET /api/v1/calendar?from=YYYY-MM-DD&to=YYYY-MM-DD`
- `POST /api/v1/calendar/events`
- `PATCH /api/v1/calendar/events/{id}`
- `DELETE /api/v1/calendar/events/{id}`

응답은 날짜별 `events` 맵이다.

```json
{
  "events": {
    "2026-06-02": [
      { "id": "...", "title": "...", "source": "event" }
    ]
  }
}
```

## UI

- 월간 달력과 오른쪽 오늘 일정 열을 같은 높이로 유지한다.
- 오늘 일정이 많으면 목록 내부 스크롤을 사용한다.
- 일정 추가 버튼은 오른쪽 열 하단 하나만 둔다.
- 하단에는 일정 상태 요약 카드 4개를 표시한다.
- 캘린더 AI 버튼은 calendar 스코프 채팅을 열고 실제 질문을 전송한다.
