## 표시 데이터

- 마감일(`deadline`)이 있는 봉우리들의 점.
- 점 색은 상태에 따라(꽃: `brand.mint_growth`, 열매: `brand.primary_leaf`, 시듦: `accent.amber_schedule`, 썩음: `accent.rose_care`).

## 뷰

- 월 / 주 토글. 쿼리 파라미터로 동기화.

## API

- `GET /calendar?from=YYYY-MM-DD&to=YYYY-MM-DD` — 셀별 봉우리 분포.
- 응답:
  ```
  {
    "ok": true,
    "data": {
      "cells": [
        { "date": "2026-05-17", "buds": [{ "id": "...", "title": "...", "status": "fruit", "plant_id": "..." }] }
      ]
    }
  }
  ```

## AI 요약

- 우측/하단 텍스트는 진입 시 1회 LLM 호출로 생성.
- 새로고침 버튼으로 재호출.

## 상호작용

- 셀 클릭 → 봉우리 리스트 팝오버.
- 항목 클릭 → `/plants/[id]`로 이동(봉우리 상세 패널 자동 열림).
