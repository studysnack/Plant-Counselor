# 알림

## 종류

| kind | 발생 조건 |
| --- | --- |
| `bud_wilting` | 자동 전이로 시듦 |
| `bud_rot` | 오래 시든 봉우리가 썩음 |
| `deadline_warning` | 마감 임박 |
| 관리자 발송 kind | 관리자 알림 발송 화면 |

## API

| 메서드 | 경로 | 설명 |
| --- | --- | --- |
| GET | `/api/v1/notifications` | 기본 미확인 목록 |
| GET | `/api/v1/notifications?include_read=true` | 읽은 알림 포함 기록 |
| POST | `/api/v1/notifications/{id}/ack` | 한 개 읽음 |
| POST | `/api/v1/notifications/ack-all` | 모두 읽음 |

사이드바 알림 팝오버는 기본 알림 3개까지 자연스럽게 보이고, 4개부터 목록 내부
스크롤을 사용한다. 상세를 펼쳐도 팝오버 전체 높이가 계속 늘어나지 않는다.

알림 기록과 읽음 상태는 `notifications` 테이블에 누적한다. 마감 임박 알림은 같은
봉우리의 미확인 알림이 있으면 스케줄러가 중복 생성하지 않는다.
