# 통계 시스템

관련 문서: [[Web/01_페이지/홈]], [[GardenState]], [[Bud]], [[Web/03_LLM/Skill_개요]]

---

## 집계 항목

| 항목 | 정의 |
|---|---|
| `active_concerns` | `type='concern'` & 활성 상태 |
| `active_schedules` | `type='schedule'` & 활성 상태 |
| `harvested_this_month` | 이번 달 `harvested`로 전이된 봉우리 수 |
| `wilting_count` | `status='wilting'` |
| `rot_count` | `status='rot'` & `disappeared_at IS NULL` |
| `plants_total` | 사용자 식물 총수(아카이브 제외) |
| `plants_active` | 활성 봉우리 1개 이상 식물 수 |

---

## 캐시 전략

- [[GardenState]]의 `summary_cache`에 저장.
- 갱신 트리거: 봉우리 생성/상태 전이/삭제, 식물 생성/삭제, `transition_scan` 종료.
- `GET /stats/summary` 호출 시 만료(5분 이상 경과) 확인 후 필요 시 갱신.

---

## API

- `GET /stats/summary` — 캐시값 반환.
- `GET /stats/full?scope=...&plant_id=..&period=...` — 즉시 계산 (`get_statistics` Skill과 동일).

---

## 월/주 기준

- 사용자 타임존 기준 현재 달/주.
- 주는 월요일 시작.
