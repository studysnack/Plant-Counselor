# 통계 시스템

`GardenStateService.refresh_summary()`가 현재 식물과 봉우리를 Python에서 집계한다.

| 항목 | 정의 |
| --- | --- |
| `active_concerns` | 활성 상태의 고민 봉우리 |
| `active_schedules` | 활성 상태의 일정 봉우리 |
| `harvested_this_month` | 이번 달 수정된 수확 봉우리 |
| `wilting_count` | 시든 봉우리 |
| `rot_count` | 썩은 봉우리 |
| `total_plants` | archive 제외 식물 수 |

## API와 스킬

- `GET /api/v1/stats/summary`: 홈과 캘린더 요약
- `GET /api/v1/briefing/today`: 현재 통계를 포함한 브리핑
- `get_statistics`: AI용 범위 통계 스킬

`/stats/full` 엔드포인트는 현재 없다.
