# 봉우리 생애주기

```text
bud -> flower -> fruit -> harvested
               \
                -> wilting -> rot
```

## 진행률 자동 전이

| 진행률 | 상태 |
| --- | --- |
| 60% 이상 | `flower` |
| 85% 이상 | `fruit` |

`update_bud_progress`와 직접 진행률 UI는 기본적으로 위 기준을 적용한다. 수확은
진행률 `100%`를 달성한 봉우리만 가능하며 `harvest_bud`를 사용한다. 포기는
`abandon_bud`를 사용한다.

일정 기간 활동이 없으면 APScheduler 스캔이 `wilting`, 이후 `rot`로 바꾼다. 정원
픽셀 화면에서 수확된 봉우리는 새싹 형태로 남고, 썩어 사라진 봉우리는 성장 레이어도
제거된다.

상태 변경은 `bud_history`에 기록한다.

## 상태 의미

| 상태 | 의미 |
| --- | --- |
| `bud` | 생성 직후, 진행 시작 |
| `flower` | 활발히 진행 중 |
| `fruit` | 마무리 단계 |
| `harvested` | 완료 |
| `wilting` | 오래 활동 없음 |
| `rot` | 포기 또는 장기 방치 |

## 부가 정보

- `type="concern"`은 고민, `type="schedule"`은 추적 일정이다.
- `deadline`은 선택값이며 캘린더와 마감 임박 알림에서 사용한다.
- 직접 삭제는 `DELETE /api/v1/buds/{id}`를 사용한다.
