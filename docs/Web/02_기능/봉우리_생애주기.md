# 봉우리 생애주기

관련 문서: [[Web/01_페이지/식물]], [[Web/02_기능/상태_자동전이]], [[Bud]], [[Web/03_LLM/Skill_개요]]

---

## 상태 목록

| 상태 | 의미 |
|---|---|
| `seed` | 생성 직후 |
| `bud` | 매달려 인식됨 |
| `flower` | 활발히 진행 중 |
| `fruit` | 마무리 직전 |
| `harvested` | 완료 |
| `wilting` | 정체 |
| `rot` | 포기됨 |

---

## 정상 흐름

`seed → bud → flower → fruit → harvested`

- **seed → bud**: 생성 직후 자동 전이.
- **bud → flower**: "본격적 진행" 발화 또는 진행률 임계 이상.
- **flower → fruit**: 마무리 단계 발화 또는 진행률 임계 이상.
- **fruit → harvested**: "끝났어/해결됐어" 발화 → `harvest_bud` Skill.

## 분기

- **Any → wilting**: 일정 기간 변화 없음. [[Web/02_기능/상태_자동전이]] 백그라운드 작업.
- **Any → rot**: 사용자 명시적 포기 발화 → `abandon_bud` Skill.
- **wilting → bud/flower**: 사용자가 재시작 발화.
- **rot → 사라짐**: 임계 일수 후 `disappeared_at` 설정(데이터 보존).

---

## 진행률

- 0~100 정수.
- LLM이 발화에서 추정 → `update_bud_progress` Skill로 갱신.
- `auto_transition=true`(기본)이면 임계 도달 시 상태도 자동 전이.

---

## 상태 변경 이력

- `bud_history` 테이블에 append-only로 저장.
- `from_status`, `to_status`, `at`, `reason`.
- `reason`은 `auto:wilting_threshold`, `user:끝났어` 같은 짧은 문자열.

---

## 마감일

- 선택적. [[Web/02_기능/캘린더]]와 [[Web/02_기능/알림]]에서 사용.
- 변경은 `set_deadline` Skill을 통해서만.

- `concern`(고민) 또는 `schedule`(일정).
- 통계에서 분리 카운트.
