# 데이터 백업 / 복구

관련 문서: [[Web/01_페이지/설정]], [[DB_스키마]], [[API_엔드포인트]]

---

## 내보내기

- `GET /me/export` → 사용자 데이터 zip 다운로드.
- zip 내용: 사용자별 모든 테이블 행을 JSON 파일들로 직렬화 + `manifest.json`(스키마 버전).
- API 키 등 민감 정보는 체크박스로 포함 여부 선택.

## 가져오기

- `POST /me/import` (multipart, zip).
- 서버는 manifest로 호환성 검사 후:
  - **덮어쓰기**: 현재 사용자 데이터를 비우고 복원.
  - **병합**: id 충돌 시 새 id 발급해 추가.

## 자동 스냅샷

- [[백그라운드_작업]]의 일 1회 스냅샷.
- `snapshots` 테이블 + 파일 본체(객체 스토리지 또는 서버 디스크).
- 보관 기간 기본 7일, [[Web/01_페이지/설정]]에서 변경 가능.
- 복구: `POST /backup/restore/{snapshot_id}`.

## 무결성 검사

- `POST /backup/verify` — 모든 JSON 필드 스키마, 외래키 일관성, 상태 머신 유효성 검사.
- 손상 행은 격리 테이블 `quarantine` 또는 보고만.
