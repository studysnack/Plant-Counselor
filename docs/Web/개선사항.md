# 개선 후보

> 최종 점검: 2026-06-04

정원 뷰, 사이드바 아이콘, 채팅 푸시 레이아웃, 스코프별 대화 기록, 식물 세션 진입,
주요 사용자 화면 반응형 레이아웃, 관리자/랜딩/로그인 세부 반응형, 봉우리의 다른
식물 이동은 이미 구현됐다.

현재 남은 개선 후보는 다음과 같다.

- 식물 이름과 설명 직접 편집 UI
- 봉우리 제목과 detail 인라인 편집 UI
- 시간 문자열 `HH:MM` 정규화
- 봉우리 정렬 옵션
- 반복 일정
- 통계 차트
- 웹 MVP 자동화 테스트
- 역사 문서 추가 정리

기능 추가 전에 이미 존재하는 API를 확인한다. 식물 patch와 봉우리 patch API는 있지만
사용자 UI가 충분하지 않은 영역이 있다.
