# plant-counselor

나의 계획, 고민, 일정 등을 식물로 시각화 하는 프로그램이다.

---

## 사전 정보

- 오직 python만 사용하여 제작해야함.
- pygame 위주 사용
- 로컬 데이터  저장 사용(폴더 기반, json 데이터 형식)

## 구두 설명

기존에 내가 버튼을 직접 조정하는 방식으로 작동하지 않는다. 모두 llm 기반으로 작동한다.
예시: "요즘 @@ 고민이 있어." -> @@ 고민 식물 생성, "지금 OO 일정이 생겼어" -> OO 일정 식물 생성.

그리고 그 고민이나 일정이 점점 완성되어가면 식물에 맺혀있던 식물이 꽃이 되었다가 열매가 되었다가 수확되는 흐름. 만약 고민을 포기하거나 일정을 포기하면 그 봉우리는 썩어 사라짐.

로컬 기반 회원가입, 로그인으로 데이터 분리
유저별 로컬 폴더 안에 다음 데이터가 들어간다. ( 식물 폴더, user 정보, 현재 상태 정보 ), 각 식물 폴더에는 (그 식물에 대한 정보 파일, 각 봉우리에 대한 정보 파일)이 들어간다. 대부분 폴더 혹은 json 형태로 제작한다.

홈 화면에는 통계를 보여준다.
(진행중인 고민, 마무리 지은 고민, 진행중인 일정 등등)
(식물 관리 보드, 캘린더 AI)
(시들고 있는 식물)

식물 화면에서는 식물에 맺힌 고민이나 일정을 시각적으로 볼 수 있다.
내가 고민하는 분야(학업, 돈, 연애 ...)마다 식물이 다르기 때문에 구분하여 볼 수 있다.
분야에도 여러 고민이 있기 때문이다.

AI에게 새로운 고민이나 일정이 생겼다고 말하면 AI가 관련된 식물을 찾아서 연결해준다. 없다면 생성한다. "이 고민/일정 은 OO 식물과 관련이 있는데, 이 식물에 꽃을 피울까요?"라고 질문한 후 연결한다. 없다면 생성한다.
