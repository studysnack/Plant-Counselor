# 상태 자동 전이

> 백그라운드 작업이 주기적으로 모든 사용자의 봉우리를 검사해 시간 기반 전이를 수행.

관련 문서: [[봉우리_생애주기]], [[알림]], [[백그라운드_작업]], [[설정]]

---

## 실행 시점

- 운영: APScheduler/Celery `transition_scan` 잡(기본 10분 주기). [[백그라운드_작업]] 참고.
- 사용자 진입 시 추가 1회 — Next.js 서버 컴포넌트가 `/stats/summary`를 받아오기 전에 백엔드가 lazy 검사 실행.

---

## 검사 항목

1. 활성 봉우리(`seed/bud/flower/fruit/wilting`)의 `last_progress_at` 확인.
2. 임계 일수 초과 → `wilting`으로 전이.
3. `wilting`이 추가 임계를 넘으면 [[알림]] 큐에 회고 제안 추가. **자동 포기는 하지 않는다.**
4. `deadline`이 임박한 봉우리는 알림 큐에 적재.
5. `rot` 상태가 설정 일수 초과 → `disappeared_at` 세팅(UI에서 숨김, 데이터 보관).
6. 활성 봉우리 0인 식물은 `status='dormant'`.

각 임계값은 [[User#garden_rules]]에서 사용자별로 변경.

---

## 비활성 모드

`garden_rules.auto_transition=false`인 사용자에 대해서는 1·2·6을 수행하지 않는다. 4(마감 알림)와 5(rot 만료)는 유지.

---

## 이력 기록

- 자동 전이도 `bud_history`에 기록. `reason`은 `auto:...` 접두.

---

## 사용자 타임존

- 일/주/달 경계는 사용자 `timezone` 기준.
- 시각 비교는 UTC로 저장된 timestamptz에 사용자 타임존 적용해 계산.
