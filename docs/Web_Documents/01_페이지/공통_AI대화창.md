# 공통 AI 대화창

> 모든 화면 우측에서 슬라이드 인되는 패널. 어디서나 호출 가능.

관련 문서: [[LLM_흐름]], [[시스템_프롬프트]], [[Skill_개요]], [[ConversationLog]], [[채팅_스트리밍]]

---

## 현재 구현 상태

- **오버레이 방식**: 패널이 열리면 배경에 반투명 블러 오버레이 + 우측 400px 고정 패널.
- 닫기: 오버레이 클릭 또는 X 버튼.
- 스코프: `chatStore`의 `scope`(kind + id)를 요청 바디에 포함.

## 계획: 푸시 레이아웃으로 전환

- 패널이 열리면 메인 콘텐츠가 좌측으로 밀림 (오버레이/블러 없음).
- 콘텐츠와 채팅을 동시에 볼 수 있는 환경.
- 자세한 사항: [[개선사항]]

---

## 호출 방법

- 사이드바의 채팅 버튼 (현재 사이드바에 위치).
- 특정 봉우리/식물의 "AI에게 묻기" 메뉴.
- 키보드 단축키 (`chatStore.open()` 직접 호출 가능).

> 이전: 우하단 플로팅 버튼 → **현재: 사이드바 버튼**으로 변경.
> 계획: 사이드바를 아이콘 전용으로 전환하면서 채팅 아이콘 호버 툴팁으로 노출.

---

## 컨텍스트 자동 주입

패널이 열릴 때 클라이언트는 다음을 요청 바디에 포함시킨다.

| 항목 | 값 |
|---|---|
| 현재 화면 | `current_screen` (예: "웹") |
| 스코프 | `scope`: `global` / `plant` / `bud` |
| 스코프 ID | `scope_id`: 해당 식물/봉우리 ID |

서버는 이 컨텍스트를 시스템 프롬프트 변수에 넣어 LLM 호출.

---

## 통신

- `POST /chat/message` — 사용자 메시지 송신.
- 응답은 **SSE 스트림**. 토큰 단위로 도착하면 화면에 점진 표시.
- `tool_result` 이벤트 수신 시 관련 TanStack Query 캐시를 자동 무효화.

자세한 프로토콜: [[채팅_스트리밍]].

---

## 현재 표시 영역

- **헤더**: 식물 아이콘, "AI 정원사" 제목, 스코프 라벨("전체 정원 컨텍스트" / "식물 컨텍스트"), 온라인 배지, 닫기 버튼.
- **대화 영역**: AI/사용자 메시지 풍선. 빈 화면에는 환영 메시지 + 빠른 시작 질문 버튼 3개.
- **입력창**: 자동 높이 textarea + 전송 버튼. Enter로 전송, Shift+Enter 줄바꿈.

---

## 대화 세션

- 현재: 화면 새로고침 시 대화 초기화 (메모리 상태만 유지).
- 계획: DB 저장 + 세션 구분 + 이력 접근 UI. 자세한 사항: [[개선사항]].
