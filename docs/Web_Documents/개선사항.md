## 1. 정원 뷰 — 그래픽 정원으로 전환

### 현재 상태
- `/plants` 페이지가 카드 그리드로 식물 목록을 표시.

### 목표
- 잔디 바닥(GrassFloor) 위에 식물이 **실제로 심어진 정원 풍경**.
- 각 식물은 `PlantSprite` 컴포넌트로 픽셀 아트 렌더링.
  - 종(species), 상태, 진행률 props로 레이어 합성.
  - `image-rendering: pixelated`로 nearest-neighbor 보장.
- 봉우리 수/상태에 따라 식물이 자라는 시각적 변화.
- 애니메이션: 바람에 흔들리는 효과, 수확 시 파티클 등.
- 빈 땅: 아직 식물이 없는 토지 구역 표시.

### 구현 참고
- `components/pixel/PlantSprite.tsx` — 레이어 합성
- `components/pixel/GrassFloor.tsx` — 잔디 바닥 배경
- `public/assets/` — 픽셀 아트 에셋

## 2. 사이드바 — 아이콘 전용 미니멀

### 현재 상태
- 텍스트 라벨이 포함된 사이드바.

### 목표
- **아이콘만** 표시. 라벨은 호버 시 툴팁으로만 노출.
- 최소한의 공간 차지 (40~48px 너비).
- 채팅 버튼 포함 (플로팅 버튼 제거).
- 현재 페이지 아이콘 강조.

### 구현
- `components/layout/Sidebar.tsx` 수정
- 아이콘: SVG 또는 픽셀 아트 아이콘

## 3. 채팅 패널 — 푸시 레이아웃

### 현재 상태
- 오버레이 방식: 패널이 배경 위에 떠서 열림. 배경에 반투명 블러 오버레이.
- 콘텐츠가 가려짐.

### 목표
- **푸시 레이아웃**: 채팅 패널이 열리면 메인 콘텐츠 영역이 좌측으로 밀림.
- 채팅과 정원을 동시에 볼 수 있는 환경.
- 오버레이·블러 없음.
- 패널 너비 약 360~400px. 메인 영역은 남은 공간 차지.

### 구현
- `(app)/layout.tsx`에서 `chatOpen` 상태에 따라 메인 영역 margin-right 조절
- 또는 CSS Grid/Flex로 패널 show/hide 시 레이아웃 재계산
- `ChatPanel.tsx` position 변경: `fixed` → relative/flex child

## 4. 채팅 세션 — DB 저장 + 세션 구분

### 현재 상태
- 대화가 메모리 상태만 유지. 새로고침 시 초기화.
- 서버의 `ConversationService`는 메시지를 DB에 저장하지만 프론트에서 이력을 불러오지 않음.

### 목표
- **세션 구분**: 날짜별 또는 사용자가 명시적으로 "새 대화" 시작 시 세션 분리.
- **대화 이력 UI**: 과거 세션을 채팅 패널에서 선택·열람 가능.
- 채팅 패널 헤더에 세션 목록 접근 버튼.
- `GET /conversations` 엔드포인트 활용.

### 구현
- `ChatPanel.tsx` — 세션 목록 사이드 패널 또는 드롭다운
- `lib/api/chat.ts` — `listConversations()`, `getConversationMessages()` 추가
- `TanStack Query` 키: `["conversation", { scope, scopeId }]`

## 5. 식물 상세 채팅 — 식물 스코프 세션

### 현재 상태
- 채팅이 항상 `global` 스코프로 열림 (또는 수동으로 scope 설정).
- 식물 상세 페이지에서 채팅을 열어도 식물 컨텍스트가 자동 주입되지 않음.

### 목표
- `/plants/[id]` 페이지에서 채팅 열기 → 해당 식물로 화면 줌인 효과.
- 채팅이 `plant` 스코프(`scope_id = plant.id`)로 자동 활성화.
- 해당 식물의 과거 세션 그룹이 채팅 이력에서 분리 표시.
- 봉우리 클릭 후 "AI에게 묻기" → `bud` 스코프로 자동 전환.

### 구현
- `chatStore.setScope({ kind: "plant", id: plantId })` 호출 후 `chatStore.open()`
- 세션 이력에서 scope별 필터링

## 6. 디자인 — 깊이 및 텍스처 강화

### 현재 상태
- 평면적이고 단순한 UI. 그림자/깊이감 부족.

### 목표
- 더 많은 **그림자(shadow)** 와 **깊이감**: 카드, 패널, 버튼에 레이어감.
- 배경에 은은한 **텍스처**: 잔디 패턴, 흙 느낌의 사이드바 배경 등.
- 봉우리/식물 상태 전환 시 부드러운 애니메이션.
- 전체적으로 "정원 앱"다운 유기적인 느낌.

### 구현
- `globals.css` CSS 변수 확장: `--shadow-lg`, `--shadow-xl`, 텍스처 배경 변수
- 카드 컴포넌트에 `box-shadow` 추가
- 픽셀 아트 에셋 도입 (잔디, 흙, 돌 타일)
