## 알림 큐

엔진: [[클래스_함수_사전#NotificationQueue]]

큐는 메모리에 보관되며 다음 종류의 알림을 담는다.

| 종류 | 트리거 |
|---|---|
| `daily_briefing` | 접속 시 1회 |
| `wilting_warning` | [[Archive/Pygame/02_기능/상태_자동전이]]에서 `wilting` 진입 |
| `wilting_review` | `wilting` 추가 임계 초과 — AI 회고 제안 |
| `deadline_soon` | 마감일이 임계 안에 들어옴 |
| `rot_disappeared` | rot이 시각적으로 사라진 직후 1회 |
| `idle_plant` | 활성 봉우리 0인 식물에 장기간 손대지 않음 |

---

## 오늘의 정원 메시지

- 접속 시 [[get_garden_briefing]]을 호출해 한 문단 텍스트를 받는다.
- [[Web/01_페이지/홈#2-오늘의-정원-메시지]] 영역에 표시.
- 하루에 한 번만 자동 갱신, 사용자가 새로고침 누르면 다시 호출.

---

## 표시 방식

- [[Web/01_페이지/홈]] 진입 시 작은 토스트로 1~2개의 알림을 띄운다.
- 토스트 클릭 시 [[Web/01_페이지/공통_AI대화창]]이 해당 컨텍스트와 함께 열린다.
- 알림 센터 패널(우측 슬라이드)에서 전체 목록 확인 가능.

---

## 사용자 설정과의 연결

- [[Web/01_페이지/설정#2-AI-설정]]에서 자발 발화를 끄면 알림이 큐에는 쌓이지만 토스트로는 노출되지 않는다.
- 임계 일수는 [[Web/01_페이지/설정#3-정원-규칙]]에서 변경.
