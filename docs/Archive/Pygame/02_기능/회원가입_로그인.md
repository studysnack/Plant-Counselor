# 회원가입 / 로그인

관련 문서: [[Web/01_페이지/설정]], [[폴더_구조]], [[User_JSON]]

---

## 첫 실행 시

- 앱이 켜지면 [[클래스_함수_사전#LoginScene]]이 가장 먼저 표시된다.
- 화면 요소: 로고, 사용자 선택 드롭다운(이미 가입된 사용자 목록), 비밀번호 입력, 로그인 버튼, "회원가입" 링크.
- 사용자 목록은 [[폴더_구조]]의 `users/` 폴더 안의 사용자 폴더 이름을 스캔해 만든다.

---

## 회원가입

1. 닉네임 입력(2~16자, 영문/한글/숫자).
2. 비밀번호 입력(2회 확인, 최소 길이 규칙).
3. 닉네임 중복 검사 — `users/<nickname>/` 폴더 존재 여부로 판단.
4. 통과 시 [[폴더_구조]]에 따라 사용자 폴더와 기본 파일 트리를 생성.
5. [[User_JSON]]에 `id`, `nickname`, `password_hash`, `created_at` 저장.
6. 자동 로그인되어 [[Web/01_페이지/홈]]으로 진입.

비밀번호는 평문 저장 금지. 해시는 [[클래스_함수_사전#PasswordHasher]] 참고.

---

## 로그인

1. 닉네임 선택 또는 입력.
2. 비밀번호 입력.
3. [[클래스_함수_사전#UserManager]]가 해시 검증.
4. 성공 시 현재 세션에 사용자 컨텍스트를 적재하고 [[Web/01_페이지/홈]]으로 이동.
5. 실패 시 카운트 증가. 5회 실패 시 일정 시간 입력 차단.

---

## 세션과 자동 로그인

- 마지막 로그인 사용자를 기억(`users/_last.json`).
- "이 PC에서 자동 로그인" 옵션 사용 시 다음 실행 때 비밀번호 없이 진입(보안 경고 표시).

---

## 로그아웃

- [[Web/01_페이지/설정#계정]]에서 트리거.
- 세션 메모리 클리어, [[LoginScene]]으로 복귀.

---

## 계정 삭제

- [[Web/01_페이지/설정#계정]]의 "계정 삭제" 버튼.
- 확인 모달에서 닉네임을 다시 입력하게 해 오타 방지.
- 확정 시 사용자 폴더 전체 제거. 백업 가능 안내 표시.
