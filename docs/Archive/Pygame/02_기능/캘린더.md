# 캘린더

> [[Web/01_페이지/홈#4-캘린더-AI]]에 표시되는 월/주 캘린더와 AI 요약.

관련 문서: [[Web/01_페이지/홈]], [[Bud_JSON]], [[Archive/Pygame/02_기능/알림]], [[get_statistics]]

---

## 표시 데이터

- 마감일(`deadline`)이 있는 봉우리들의 점.
- 점 색은 봉우리 상태에 따름(꽃: 연한, 열매: 진한, 시듦: 갈색, 썩음: 검정).
- 동일 날짜에 여러 봉우리가 있으면 점이 누적되어 표시되고 호버 시 목록을 보여준다.

---

## 뷰

- 월 뷰: 한 화면에 한 달, 일자별 셀.
- 주 뷰: 7일을 가로로 펼침. 일자별 큰 셀에 봉우리 목록을 직접 표시.
- 토글로 전환.

---

## AI 요약

- 캘린더 우측 또는 하단에 한 문단 텍스트.
- 사용자가 캘린더에 진입할 때 LLM이 이번 주/달의 봉우리 분포를 요약해 표시.
- 갱신: 페이지 진입 시 1회, 새로고침 버튼 클릭 시 재호출.

---

## 상호작용

- 셀 클릭 → 그 날에 마감 또는 진행 예정인 봉우리 리스트 팝오버.
- 봉우리 항목 클릭 → [[Web/01_페이지/식물#봉우리-상세-패널]]로 이동.

---

## 마감 임박 알림과의 연동

- 마감일이 [[Web/01_페이지/설정#3-정원-규칙]]의 임계 안에 들어오면 셀에 강조 표시.
- 동일 항목이 [[Archive/Pygame/02_기능/알림]]의 큐에도 추가된다.
