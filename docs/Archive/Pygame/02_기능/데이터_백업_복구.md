# 데이터 백업 / 복구

관련 문서: [[Web/01_페이지/설정]], [[폴더_구조]]

---

## 내보내기

- [[Web/01_페이지/설정#5-데이터]]의 "백업 만들기" 버튼.
- 동작:
  1. 사용자 폴더 `users/<nickname>/` 전체를 임시 폴더에 복사.
  2. zip 압축.
  3. 사용자가 지정한 위치에 저장. 파일명 예: `plant-counselor_<nickname>_<yyyymmdd-hhmm>.zip`.
- API 키 등 민감 파일은 사용자가 체크박스로 포함 여부 선택.

---

## 가져오기

- "백업으로 복구" 버튼.
- zip을 지정 → 검증 → 현재 사용자 폴더와 충돌 시 다음 옵션:
  - 덮어쓰기
  - 새 사용자로 가져오기(닉네임 입력)
  - 취소

---

## 자동 스냅샷

- 앱은 매번 종료 시 [[폴더_구조]]의 `users/<nickname>/snapshots/`에 직전 상태의 가벼운 스냅샷을 만든다(JSON 파일들만).
- 최근 N개(기본 7개)만 유지하고 오래된 것은 삭제.
- [[Web/01_페이지/설정#5-데이터]]에서 스냅샷 목록 확인/복원 가능.

---

## 데이터 무결성 검사

- [[Web/01_페이지/설정#5-데이터]]의 "데이터 무결성 검사" 버튼.
- 동작:
  1. 모든 JSON 파일을 파싱해 본다.
  2. 손상되거나 스키마에서 벗어난 파일을 보고.
  3. 해당 항목을 자동 격리(`users/<nickname>/quarantine/`)할지 묻는다.
