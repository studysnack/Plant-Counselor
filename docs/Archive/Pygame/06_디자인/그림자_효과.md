## 그림자

pygame은 box-shadow가 없으므로, 사전 렌더된 알파 패치 또는 다중 surface blit로 그림자를 시뮬레이션한다. 토큰 키만 정의해두고 [[클래스_함수_사전#ShadowRenderer]]가 구현한다.

| 토큰 키 | 의미 | 파라미터(오프셋 x, y / 블러 / 알파) |
|---|---|---|
| `shadow.none` | 없음 | - |
| `shadow.sm` | 칩/입력창 호버 | 0, 1, 2, 0.06 |
| `shadow.md` | 일반 카드 | 0, 4, 10, 0.08 |
| `shadow.lg` | 패널/모달 | 0, 12, 24, 0.12 |
| `shadow.inset` | 입력창 내부 우묵함 | inset |

---

## 테두리

| 토큰 키 | 두께 | 색 |
|---|---|---|
| `border.none` | 0 | - |
| `border.subtle` | 1 | `border.subtle` |
| `border.strong` | 2 | `border.strong` |
| `border.focus` | 2 | `brand.primary_leaf` |

라운드는 [[간격_레이아웃#라운드corner-radius]] 참고.

## 상태(state) 효과

각 인터랙티브 컴포넌트는 5개 상태를 가진다.

| 상태 | 정의 |
|---|---|
| `default` | 기본 |
| `hover` | 마우스 오버 |
| `pressed` | 클릭 중 |
| `focused` | 키보드 포커스 |
| `disabled` | 비활성 |

상태별 시각 변화 규칙:

- hover: 배경 1단계 짙게 또는 그림자 한 단계 강화.
- pressed: y축으로 1px 내려가는 듯한 인셋(shadow.inset).
- focused: `border.focus` 적용.
- disabled: 텍스트/아이콘 알파 0.5, 호버 효과 무시.

## 전환(transition)

pygame은 CSS transition이 없으므로 [[클래스_함수_사전#Animator]] 헬퍼로 보간한다.

| 토큰 키 | 시간(ms) | 이징 |
|---|---|---|
| `motion.fast` | 120 | ease-out |
| `motion.base` | 200 | ease-out |
| `motion.slow` | 320 | ease-in-out |

사용 예:

- 채팅 패널 슬라이드 인/아웃 — `motion.slow`
- 토스트 등장 — `motion.base`
- 버튼 hover 색 변화 — `motion.fast`

## 픽셀 식물의 미세 흔들림

- 식물 일러스트는 정적이 기본이지만, [[Web/01_페이지/설정#4-시각사운드]]의 애니메이션 강도가 `subtle` 이상이면 [[클래스_함수_사전#PlantSway]]가 잎/꽃을 매우 약하게 흔든다.
- 강도 토큰: `subtle`(±1px, 4초 주기), `rich`(±2px, 2.5초 주기).
