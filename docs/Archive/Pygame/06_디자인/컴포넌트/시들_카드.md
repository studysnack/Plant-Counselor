# 컴포넌트: 시들고 있는 식물 카드(WiltingCard)

> 홈 하단의 "시들고 있는 식물" 섹션에 등장. 부드러운 파스텔 배경이 특징.

관련 문서: [[Web/01_페이지/홈]], [[Web/02_기능/알림]], [[Web/02_기능/상태_자동전이]]

---

## 구조

```
+-------------------------------------+
| [컬러 박스] 업무 발표      [상태 점] |
| 업무 · 3일째 기록 없음              |
| [=================----] 진행률      |
| 관리: 발표 고민 10분 정리            |
+-------------------------------------+
```

- 배경 `bg.surface`, 좌측에 큰 파스텔 컬러 박스(분야 액센트의 알파 20% 또는 `brand.leaf_soft`).
- 라운드 `radius.xl`, `shadow.md`, 패딩 `space.5`.

---

## 변형 컬러

상위 [[식물_카드]]와 매핑이 동일하나, 좌측 컬러 박스는 진한 액센트 대신 옅은(soft) 톤 사용. `brand.leaf_soft`는 그대로, 나머지는 액센트 색 알파 20%([[컬러_팔레트#"soft"-배경-규칙]]).

| 변형 | 좌측 박스 |
|---|---|
| 업무/학업 | `brand.leaf_soft` |
| 건강 | `brand.mint_growth` @ 20% |
| 관계 | `accent.rose_care` @ 20% |
| 진로 | `accent.amber_schedule` @ 20% |

- 채움 색은 분야 액센트의 부드러운 톤.
