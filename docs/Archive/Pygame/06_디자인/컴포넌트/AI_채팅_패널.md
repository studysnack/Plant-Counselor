# 컴포넌트: AI 채팅 패널(ChatPanel)

> 화면 우측에서 슬라이드 인되는 대화 패널. [[Web/01_페이지/공통_AI대화창]]의 시각 구현.

관련 문서: [[Web/01_페이지/공통_AI대화창]], [[Web/03_LLM/LLM_흐름]], [[디자인_시스템]]

---

## 구조

```
┌─────────────────────────────────┐
│ [AI 아바타] 상담 AI       [온라인][X] │  ← 헤더
│ 고민과 일정을 함께 봅니다              │
├─────────────────────────────────┤
│ 현재 돌봄                 [긴장 높음] │  ← 상태 카드
│ 업무 발표 식물이 시들기 시작했어요...    │
├─────────────────────────────────┤
│ 대화                              │
│ ┌────────────────────────────┐ │
│ │ AI                           │ │
│ │ 오늘은 발표 준비와 ...        │ │
│ └────────────────────────────┘ │
│           ┌─────────────────┐ │
│           │ 나                │ │
│           │ 먼저 돌봐야 할... │ │
│           └─────────────────┘ │
├─────────────────────────────────┤
│ 다음 행동 제안               [추천] │
│ 발표 자료를 20분 단위로 나누고...     │
│ [일정에 넣기][식물 기록]              │
├─────────────────────────────────┤
│ 바로 물어보기                       │
│ [일정 정리][감정 기록][식물 상태]     │
├─────────────────────────────────┤
│ [IMG 이미지 파일]                  │
│ [TXT 텍스트 파일]                  │
│ [MD Markdown 파일]                │
│ [... 내 파일에서 선택]              │
├─────────────────────────────────┤
│ [+] [입력창 ............] [↑]    │
│ Enter로 전송                       │
└─────────────────────────────────┘
```

- 폭 **360px**(좁은 화면) ~ **400px**.
- 배경 `bg.surface`, 그림자 `shadow.lg`, 좌측 1px `border.subtle`.
- 슬라이드 인/아웃: `motion.slow`.

---

## 헤더

- 아바타: 둥근 32×32 픽셀 일러스트(잎 아이콘).
- 제목 `text.h2`, 부제 `text.body_sm`.
- 우측에 상태 배지(`text.label`, 옅은 그린)와 닫기 X.

---

## 상태 카드(현재 돌봄)

- 패스텔 그린 배경 `brand.leaf_soft`, 라운드 `radius.lg`, 패딩 `space.4`.
- 우상단 작은 칩으로 긴장도 표시.

---

## 대화 영역

- 메시지 풍선:
  - AI 메시지: 좌측 정렬, 배경 `bg.surface_alt`, 라운드 `radius.lg`.
  - 사용자 메시지: 우측 정렬, 배경 `brand.leaf_soft`.
  - 메시지 위에 작은 라벨 "AI"/"나" (`text.caption`).
- 메시지 사이 수직 간격 `space.3`.

---

## 다음 행동 제안 카드

- 옅은 회색 배경 `bg.surface_alt`, 라운드 `radius.lg`.
- 하단에 액션 버튼들([[버튼]] secondary 변형).

---

## 바로 물어보기 칩

- [[칩_뱃지]] 컴포넌트 사용. 클릭 시 미리 정의된 프롬프트가 입력창에 채워지고 전송된다.

---

## 파일 첨부 메뉴

- 슬라이드업 시트 형태. 항목들은 좌측 작은 라벨 박스 + 텍스트.
- 라벨 박스 색: `IMG`(라일락), `TXT`(베이지), `MD`(스카이), `...`(그린).

---

## 입력창과 전송

- 입력창 라운드 `radius.lg`, 그림자 `shadow.sm`.
- 좌측 + 버튼(파일 첨부), 우측 ↑ 전송 버튼.
- 아래 "Enter로 전송" 힌트 `text.caption`.
