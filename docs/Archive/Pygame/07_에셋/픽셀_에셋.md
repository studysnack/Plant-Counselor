# 픽셀 에셋

> 식물(잎/줄기/꽃/열매), 화분, 바닥(잔디), 배경 등 모든 픽셀 이미지의 명세와 폴더 구조.

관련 문서: [[디자인_시스템]], [[식물_정원_레이아웃]], [[식물_카드]], [[Plant_JSON]], [[로고]]

> 로고는 픽셀 에셋이 아니라 별도 브랜드 자산이다. [[로고]] 참고.

## 폴더 구조

```
assets/
└─ pixels/
   ├─ pots/                      # 화분
   │  ├─ pot_clay.png            # 16x16 또는 24x24
   │  ├─ pot_clay@2x.png
   │  └─ pot_<species>.png       # 식물 종에 매칭된 변형
   ├─ plants/
   │  ├─ <species>/              # 식물 종별 폴더
   │  │  ├─ stem_a.png           # 줄기 단계 (a,b,c…)
   │  │  ├─ stem_b.png
   │  │  ├─ leaf_a.png           # 잎 단계
   │  │  ├─ leaf_b.png
   │  │  ├─ flower.png           # 꽃 1프레임
   │  │  ├─ fruit.png            # 열매 1프레임
   │  │  ├─ bud.png              # 봉오리 상태
   │  │  ├─ seed.png             # 씨앗 상태
   │  │  ├─ wilting.png          # 시듦 오버레이
   │  │  └─ rot.png              # 썩음 오버레이
   ├─ floor/
   │  ├─ grass_01.png            # 잔디 타일(가로 반복)
   │  ├─ grass_02.png
   │  └─ deco_grass_tuft.png     # 풀 더미 데코
   ├─ background/
   │  ├─ sky_day.png
   │  ├─ sky_night.png
   │  └─ vignette_overlay.png
   ├─ icons/                     # UI 아이콘(픽셀 또는 라인)
   │  ├─ home.png
   │  ├─ plant.png
   │  ├─ calendar.png
   │  ├─ chat.png
   │  └─ settings.png
   └─ characters/

   ├─ Pretendard-Regular.otf
   ├─ Pretendard-Bold.otf
   ├─ JetBrainsMono-Regular.ttf
```

## 해상도 규칙

- 기본 픽셀 그리드: **16px** (모든 식물 파트의 베이스 단위).
- 1배 파일과 2배(`@2x`) 파일을 둘 다 둔다.
- 화면 DPI 자동 감지 후 [[클래스_함수_사전#AssetLoader]]가 적절한 배율 로드.
- 업스케일은 항상 nearest-neighbor 보간. anti-aliasing 금지.

---

## 명명 규칙

- 모두 소문자 snake_case.
- 식물 종 키는 [[Plant_JSON#species]] 값과 일치(`tree_oak`, `vine_morning_glory` 등).
- 파일 끝에 `_a`, `_b` 같이 성장 단계 인덱스를 붙인다.
- 상태 오버레이는 키워드(`wilting`, `rot`) 그대로.

---

## 식물 합성

식물 한 그루는 다음 레이어를 z-order에 따라 합성해서 그린다.

```
( 바닥 그림자 ) → 화분 → 줄기 → 잎 → (꽃 or 열매) → (시듦/썩음 오버레이)
```

- 줄기/잎의 단계는 [[Web/02_기능/봉우리_생애주기]]에 따라 달라진다.
  - `seed` → `seed.png`만
  - `bud` → 줄기 a + 잎 a + 봉오리
  - `flower` → 줄기 b + 잎 b + 꽃
  - `fruit` → 줄기 b + 잎 b + 열매
  - `wilting` → 위의 어느 단계든 + `wilting.png` 오버레이
  - `rot` → `rot.png` 오버레이만(또는 검게 변한 식물)

## 식물 카드 썸네일

[[식물_카드]] 좌상단의 작은 픽셀 화분 썸네일.

- 크기 32×32 또는 40×40.
- 별도 파일이 아니라 위의 식물 합성을 작은 캔버스에 렌더해 생성. [[클래스_함수_사전#PlantSprite]].`render_thumbnail(size)`.

---

## 잔디 바닥

- `grass_01.png`, `grass_02.png` 등 가로 반복 가능한 타일.
- 식물 정원 화면에서 화면 아래쪽 1/3을 차지.
- 위에 `deco_grass_tuft.png`가 랜덤 시드 기반으로 분포(같은 사용자라면 항상 동일 분포).

---

## 배경

- 계절/시간대에 따라 sky 파일 변경.
- `vignette_overlay.png`는 네 모서리 어둡게 처리하는 옵션 오버레이.

---

## 아이콘

- 사이드바, 통계 카드 배지에 사용되는 아이콘은 픽셀이 아니라 깔끔한 라인/면 아이콘을 권장(SVG에서 PNG로 export).
- 사이즈 16, 20, 24, 32px 세트를 미리 만든다.

---

## 폰트

- 본문은 일반 벡터 폰트([[타이포그래피]]).
- 픽셀 강조 폰트(`DungGeunMo` 등)는 헤더 배지나 정원 화면의 식물 라벨 일부에만 선택적으로.

---

## 에셋 로딩 책임

- [[클래스_함수_사전#AssetLoader]]가 시작 시 인덱스를 만들고, 사용 시점에 lazy 로드.
- 동일 종(species)의 합성은 [[클래스_함수_사전#PlantSprite]]가 캐시.
