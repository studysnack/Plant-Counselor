# 설정 레이아웃

관련 문서: [[설정]], [[디자인_시스템]], [[간격_레이아웃]]

---

## 골격

```
+------+--------------------------------------------------+
|      | 설정                                              |
|  S   | 계정, AI, 정원 규칙, 시각/사운드, 데이터, 정보       |
|  i   +-----------+--------------------------------------+
|  d   | [탭 리스트] | [선택된 탭의 폼 카드]                  |
|  e   |  · 계정     |                                      |
|  b   |  · AI       |  여러 행의 라벨 + 컨트롤               |
|  a   |  · 정원 규칙 |                                      |
|  r   |  · 시각/사운드 |                                    |
|      |  · 데이터   |                                      |
|      |  · 정보     |                                      |
+------+-----------+--------------------------------------+
```

- 좌측 탭 폭 220px, 우측 폼 영역 flex.

---

## 탭

- 세로 리스트. 각 항목 높이 40, 라운드 `radius.md`.
- 선택 항목 배경 `brand.leaf_soft`, 글자 `brand.primary_leaf`.

---

## 폼 카드

- `bg.surface`, `radius.xl`, `shadow.md`, 패딩 `space.6`.
- 한 줄 항목 = 라벨(왼쪽, `text.body` `text.muted`) + 컨트롤(오른쪽).
- 행 사이 구분선은 `border.subtle`.

---

## 컨트롤 표준

- 토글 스위치: 폭 40, 높이 22, 트랙 라운드 `radius.pill`.
- 슬라이더(볼륨 등): 트랙 4px 두께, 노브 14px.
- 드롭다운: [[입력창]] `text` 변형 + 우측 ⌄ 아이콘.
