# 컴포넌트: 토스트 / 모달

관련 문서: [[알림]], [[디자인_시스템]]

---

## 토스트

- 화면 우상단 또는 우하단에서 등장. 폭 320px 내외.
- 배경 `bg.surface`, `shadow.lg`, 라운드 `radius.xl`, 패딩 `space.4`.
- 좌측 아이콘 배지(알림 종류별 컬러), 우측 본문.
- 등장 모션 `motion.base`, 5초 후 자동 사라짐(설정 가능).

---

## 모달

- 화면 중앙 가운데. 폭 480~560px.
- 배경 오버레이는 검정 알파 0.4.
- 모달 본체: `bg.surface`, `shadow.lg`, 라운드 `radius.xl`, 패딩 `space.6`.
- 헤더(제목), 본문, 하단 액션 행(우측 정렬, primary + secondary).

---

## 사용 사례

- 토스트: 시듦 알림, 마감 임박, 수확 축하.
- 모달: 식물 삭제 확인, 봉우리 포기 확인, 백업 복구 등.
