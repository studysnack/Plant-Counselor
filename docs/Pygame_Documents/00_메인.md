# Plant Counselor — 메인 문서

> 나의 계획, 고민, 일정 등을 식물로 시각화하는 LLM 기반 프로그램.
> 본 문서는 전체 구조를 요약하며, 세부 사항은 각 하위 문서로 분리되어 있다.

---

## 한눈에 보기

- 사용자의 **고민/일정**을 LLM과의 대화만으로 입력/관리한다.
- 모든 항목은 **식물(분야) → 봉우리(개별 항목)** 메타포로 시각화된다.
- 봉우리는 **씨앗 → 봉우리 → 꽃 → 열매 → 수확**의 생애주기를 가지며, 정체되면 **시듦**, 포기되면 **썩음**으로 이동한다.
- 데이터는 **사용자별 로컬 폴더**에 JSON으로 저장된다. 외부 서버는 사용하지 않으며, LLM API 호출만 외부로 나간다.
- LLM은 [[Skill_개요]]에 정의된 **Skill 집합**을 통해 프로그램의 모든 데이터를 조회/조작한다.

## 핵심 메타포 요약

| 식물 요소 | 의미 |
|---|---|
| 정원(Garden) | 사용자 1명의 전체 공간 |
| 식물(Plant) | 하나의 분야(카테고리) |
| 봉우리(Bud) | 개별 고민/일정 |
| 꽃(Flower) | 활발히 진행 중 |
| 열매(Fruit) | 마무리 직전 |
| 수확(Harvest) | 완료 |
| 시듦(Wilting) | 정체 상태 |
| 썩음(Rot) | 포기됨 |

전체 생애주기: **씨앗 → 봉우리 → 꽃 → 열매 → 수확**, 부수 분기 **시듦**, **썩음 → 사라짐**.

## 사용 기술 전제

- **Python**만 사용.
- **pygame** 중심의 UI.
- **로컬 JSON 파일** 저장.
- LLM은 외부 API.

세부 규칙과 화면 동작은 모두 하위 문서에 분산되어 있다.
