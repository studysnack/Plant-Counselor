# 상태 자동 전이

> 시간 기반으로 봉우리 상태를 자동 갱신하는 규칙.

관련 문서: [[봉우리_생애주기]], [[알림]], [[설정]], [[Bud_JSON]]

---

## 실행 시점

- 앱 시작 직후 1회.
- 활성 세션 중 일정 주기(기본 10분)마다.
- [[홈]] 진입 시 추가 갱신.

엔진: [[클래스_함수_사전#StateTransitionEngine]]

---

## 검사 항목

1. 모든 활성 봉우리(`seed`, `bud`, `flower`, `fruit`, `wilting`)에 대해 `last_progress_at` 확인.
2. 임계 일수(기본 7일, [[설정#3-정원-규칙]]에서 변경 가능)를 초과하면 `wilting`으로 전이.
3. `wilting` 상태가 추가 임계 일수(기본 +7일)를 넘으면 [[알림]]의 회고 제안 큐에 추가. **자동 포기는 하지 않는다.**
4. `deadline`이 임박한 봉우리는 [[알림]]의 마감 임박 큐에 추가.
5. `rot` 상태가 설정된 일수(기본 14일)를 넘으면 시각적으로 사라짐 처리. 데이터는 보관.
6. 활성 봉우리가 0인 식물은 [[Plant_JSON#status]]를 `dormant`(휴면)로 표기.

---

## 자동 전이 비활성 모드

[[설정#3-정원-규칙]]에서 "자동 상태 전이 사용"을 끄면 위의 1~6 중 1, 2, 6은 수행하지 않는다. 단 마감일 알림(4)과 rot 만료 처리(5)는 유지된다.

---

## 사용자 발화에 의한 전이

자동과 별개로 다음 발화는 즉시 전이를 일으킨다.

- "본격적으로 시작했어" → `bud → flower`
- "거의 다 끝났어" → `flower → fruit`
- "끝났어" → `* → harvested`
- "포기할래" → `* → rot`
- "다시 할래" → `wilting → bud` (또는 직전 상태)

자세한 함수 동작은 [[Skills/update_bud_status]] 참고.

---

## 이력 기록

모든 자동/수동 전이는 [[Bud_JSON#history]]에 누적된다. `reason` 필드:

- 자동: `"auto:wilting_threshold"` 등
- 수동: `"user:끝났어"` 등
