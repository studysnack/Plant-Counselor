# 통계 시스템

> [[홈#1-상단-요약-카드]]에 노출되는 수치들과 그 계산 방식.

관련 문서: [[홈]], [[GardenState_JSON]], [[Bud_JSON]], [[Skills/get_statistics]]

---

## 집계 항목

| 항목 | 정의 |
|---|---|
| `active_concerns` | 타입이 `concern`이며 상태가 활성(seed/bud/flower/fruit/wilting)인 봉우리 수 |
| `active_schedules` | 타입이 `schedule`이며 상태가 활성인 봉우리 수 |
| `harvested_this_month` | 현재 달에 `harvested`로 전이된 봉우리 수 |
| `wilting_count` | 상태가 `wilting`인 봉우리 수 |
| `rot_count` | 상태가 `rot`인 봉우리 수(아직 사라지지 않은 것만) |
| `plants_total` | 식물 수(휴면 포함) |
| `plants_active` | 활성 봉우리가 1개 이상인 식물 수 |

---

## 캐시 전략

- 매번 전체 봉우리를 스캔하지 않기 위해 [[GardenState_JSON#summary_cache]]에 저장.
- 갱신 트리거:
  - 봉우리 생성/상태 전이/삭제
  - [[상태_자동전이]] 엔진 실행 종료 시
  - [[홈]] 진입 시(보장용)

## 월/주 기준

- "이번 달"은 사용자의 로컬 시간대 기준 현재 달.
- "이번 주"는 월요일 시작.
