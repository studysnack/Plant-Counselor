# 홈 페이지

> 정원의 한눈 보기. 사용자가 로그인 직후 진입하는 기본 화면.

관련 문서: [[식물]], [[설정]], [[공통_AI대화창]], [[통계_시스템]], [[캘린더]], [[알림]]
디자인: [[홈_레이아웃]], [[통계_카드]], [[식물_카드]], [[캘린더_패널]], [[시들_카드]], [[AI_채팅_패널]]

---

## 화면 구성

홈은 위에서 아래로 다음 섹션이 순서대로 배치된다.

1. **상단 요약 카드 영역** — [[통계_시스템]]에서 계산된 수치를 카드로 표시.
2. **오늘의 정원 메시지** — LLM이 [[Skills/get_garden_briefing]]을 호출해 생성한 한 문단.
3. **식물 관리 보드** — 사용자가 가진 모든 식물의 미니 카드 그리드.
4. **캘린더 AI** — [[캘린더]] 모듈을 사용한 월/주 뷰 + AI 요약.
5. **시들고 있는 식물 섹션** — 정체된 봉우리/식물 강조.
6. **하단 고정 AI 대화 입력창** — [[공통_AI대화창]]을 통한 빠른 입력.

---

## 1. 상단 요약 카드

각 카드는 클릭 시 해당 필터가 적용된 [[식물]] 페이지 또는 상세 목록으로 이동한다.

- 진행 중인 고민 수
- 진행 중인 일정 수
- 이번 달 수확 수
- 시들고 있는 봉우리 수(주의 알림)
- 포기(썩음) 수

값은 [[GardenState_JSON]]의 `summary_cache`에서 가져오며, 진입 시 [[Manager_클래스들#GardenStateManager]]가 갱신한다.

---

## 2. 오늘의 정원 메시지

- 접속 시 자동으로 1회 생성.
- LLM이 [[Skills/get_garden_briefing]]을 호출해 정원 상태를 요약한 텍스트 한 문단을 받는다.
- 사용자가 새로고침 아이콘을 누르면 다시 호출.
- 캐시는 [[GardenState_JSON]]의 `daily_briefing` 필드에 저장.

자세한 트리거 규칙: [[알림#오늘의-정원-메시지]]

---

## 3. 식물 관리 보드

- 사용자가 가진 모든 식물의 미니 카드 그리드. 한 행에 3~4개.
- 카드 내용:
  - 식물 외형 썸네일(상태/건강도 반영)
  - 분야 이름
  - 매달려 있는 활성 봉우리 수
  - 가장 임박한 마감일 또는 "마감 없음"
- 카드 클릭 시 [[식물#식물-상세]]로 이동.
- 정렬은 활동량 순(기본) / 생성 순 / 분야명 순으로 토글 가능.

데이터 출처: [[Plant_JSON]], [[Bud_JSON]].

---

## 4. 캘린더 AI

- 월/주 단위 토글.
- 마감일이 설정된 봉우리들이 캘린더 셀에 점/이름으로 표시.
- 우측 또는 하단에 AI 요약 텍스트: 이번 주에 어떤 봉우리가 어떤 단계에 있는지.
- 항목 클릭 시 봉우리 상세로 이동.

자세한 동작: [[캘린더]]

---

## 5. 시들고 있는 식물 섹션

- [[상태_자동전이]] 규칙에 따라 `wilting` 상태인 봉우리 목록.
- 각 항목 옆에 "AI에게 상담받기" 버튼 → [[공통_AI대화창]]에 해당 봉우리 컨텍스트가 주입된 채 열림.
- 사용자의 액션(포기/재시작)은 모두 발화로 처리: AI가 [[Skills/abandon_bud]] 또는 [[Skills/update_bud_status]]를 호출.

---

## 6. 하단 고정 AI 대화 입력창

- 어디서나 동일하게 호출되는 대화창의 축소 버전.
- 자세한 동작은 [[공통_AI대화창]] 참고.

---

## 비어 있는 정원의 첫 화면

- 식물이 0개일 때는 식물 보드 자리에 안내 카드를 띄운다.
- AI가 "어떤 분야의 식물을 먼저 키우고 싶으신가요?"라고 발화.
- 사용자가 첫 발화를 입력하면 [[LLM_흐름]]에 따라 [[Skills/create_plant]] 후보가 제안된다.

---

## 화면 전환 규칙

- 좌측 또는 상단 내비게이션 바로 [[식물]], [[설정]]로 이동.
- 어떤 화면에서도 단축키 또는 항상 보이는 대화창 버튼으로 [[공통_AI대화창]]을 호출 가능.
