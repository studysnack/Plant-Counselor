# 클래스 / 함수 사전

> 프로그램 전체에서 사용되는 클래스, 멤버, 함수의 이름과 짧은 설명을 모은 종합 사전.
> 본문에는 구현 코드를 적지 않는다. 시그니처(이름·인자·반환의 의도)만 기록한다.

관련 문서: [[Manager_클래스들]], [[AI_연동]], [[UI_구조]], [[Skill_개요]]

- 멤버
  - `path_resolver`: [[#PathResolver]]
  - `file_store`: [[#FileStore]]
  - `user_manager`: [[#UserManager]]
  - `plant_manager`: [[#PlantManager]]
  - `bud_manager`: [[#BudManager]]
  - `garden_state`: [[#GardenStateManager]]
  - `conversation_manager`: [[#ConversationManager]]
  - `notifications`: [[#NotificationQueue]]
  - `transition_engine`: [[#StateTransitionEngine]]
  - `backup`: [[#BackupManager]]
  - `llm_client`: [[#LLMClient]]

  - `skill_registry`: [[#SkillRegistry]]

  - `shutdown()` — 자원 정리 및 마지막 스냅샷 생성

## PathResolver

모든 디스크 경로를 계산하는 단일 진입점. 다른 사용자 폴더로의 접근을 차단한다.

- 메서드
  - `user_root(nickname)` — 사용자 루트 경로
  - `plant_dir(plant_id)` — 식물 폴더
  - `bud_file(plant_id, bud_id)` — 봉우리 파일
  - `conversation_file(scope, scope_id)` — 대화 로그 파일
  - `garden_file()`, `user_file()`, `keys_file()`
  - `snapshot_dir()`, `archive_dir()`, `quarantine_dir()`

## FileStore

JSON 파일 읽기/쓰기 공통 유틸. 원자적 쓰기 제공.

- 메서드
  - `read_json(path)`
  - `write_json(path, obj)`
  - `atomic_write(path, bytes_data)`
  - `move(src, dst)`
  - `remove(path)`

## PasswordHasher

비밀번호 해시 검증.

- 메서드
  - `hash(password)`
  - `verify(password, hash_str)`

## UserManager

사용자 계정 라이프사이클.

- 멤버: `_current_user`, `path_resolver`, `file_store`, `hasher`
- 메서드
  - `list_users()`
  - `signup(nickname, password)`
  - `login(nickname, password)`
  - `logout()`
  - `current()`
  - `change_password(old, new)`
  - `rename(new_nickname)`
  - `delete_account(confirm_nickname)`
  - `export_user_data(dest_path)` — 현재 사용자 폴더를 내보낸다. 내부적으로 [[#BackupManager]].`export_zip`을 호출하는 얇은 래퍼.
  - `import_user_data(src_path, mode)` — 동일하게 [[#BackupManager]].`import_zip`을 호출.

## PlantManager

식물 CRUD와 매칭.

- 메서드
  - `create(name, description, species=None, color=None)`
  - `get(plant_id)`
  - `list(include_dormant=True, sort="activity")`
  - `update(plant_id, fields)`
  - `delete(plant_id, archive=True)`
  - `find_matches(query, hint_category=None, top_k=3)`
  - `increment_harvest(plant_id)`
  - `increment_rot(plant_id)`
  - `mark_dormant(plant_id)`

## BudManager

봉우리 CRUD 및 상태 전이.

- 메서드
  - `create(plant_id, title, type, detail=None, deadline=None, initial_status="seed")`
  - `get(bud_id)`
  - `list(filters)`
  - `update_status(bud_id, to_status, reason=None)`
  - `update_progress(bud_id, progress, auto_transition=True, note=None)`
  - `set_deadline(bud_id, deadline)`
  - `abandon(bud_id, reason=None)`
  - `harvest(bud_id, note=None)`
  - `mark_wilting(bud_id)`
  - `purge_disappeared(older_than_days)`

## GardenStateManager

캐시와 통계 계산.

- 메서드
  - `refresh_summary()`
  - `get_summary()`
  - `compute_stats(scope, plant_id=None, period="this_month")`
  - `build_briefing(as_of=None)`

## ConversationManager

대화 로그.

- 메서드

  - `get_history(scope, scope_id, limit=20)`
  - `search(query, scope="global", scope_id=None, limit=10)`
  - `clear(scope=None, scope_id=None)`

## NotificationQueue

자발 발화/알림.

- 메서드
  - `push(kind, payload)`
  - `pop_all()`
  - `recompute_deadlines()`
  - `recompute_wilting()`

## StateTransitionEngine

시간 기반 자동 전이.

- 메서드
  - `scan()` — 전체 봉우리 검사
  - `check_wilting()`
  - `check_rot_disappear()`
  - `check_deadlines()`

## BackupManager

백업/복구.

- 메서드
  - `export_zip(dest_path, include_keys=False)`
  - `import_zip(src_path, mode)`
  - `make_snapshot()`
  - `restore_snapshot(snapshot_id)`
  - `list_snapshots()`
  - `verify_integrity()`

## LLMClient

외부 LLM API 호출.

- 멤버: `model`, `api_key`, `timeout`, `retry_policy`
- 메서드
  - `set_model(model_id)`
  - `set_api_key(key)`
  - `chat(messages, tools=None)` — 응답 객체(텍스트 + tool_calls) 반환

## PromptBuilder

시스템 프롬프트 구성. [[시스템_프롬프트]] 템플릿 사용.

- 메서드
  - `build_system(context)` — 최종 system 메시지 문자열
  - `build_tools_catalog(skill_registry)`
  - `embed_context(current_scene, selected_ids, stats, recent_messages)`

## SkillRegistry

Skill 등록과 dispatch.

- 메서드
  - `register(skill)`
  - `get(name)`
  - `list()`
  - `build_catalog()` — JSON 스키마 카탈로그
  - `dispatch(name, args, ctx)` — Skill 실행 결과 반환

## Skill_베이스

각 Skill이 상속하는 베이스 클래스.

- 속성
  - `name`, `description`, `parameters`(JSON Schema), `requires_confirmation`
- 메서드
  - `run(args, ctx)` — `{ ok, message, data, error_code }`

각 Skill 구현 클래스(예: `CreatePlantSkill`, `CreateBudSkill`, `UpdateBudStatusSkill`, ...)는 [[Skill_개요]]의 카탈로그에 1:1 대응한다.

## ChatController

UI와 LLM 계층의 중간자.

- 멤버: `app`, `chat_widget`
- 메서드
  - `send_user_message(text)`
  - `collect_context()`
  - `handle_assistant_response(resp)`
  - `confirm_and_dispatch(skill_name, args)`

## 핵심 위젯(컨테이너)

> 화면 구조의 큰 단위. 세부 디자인은 [[디자인_시스템]] 참고. 카드/칩/버튼 같은 잎(leaf) 위젯은 아래 "디자인 구현 위젯" 섹션에 모아둔다.

### BudWidget
식물 상세에서 봉우리 하나의 시각 노드. 디자인: [[식물#봉우리-시각화-영역]].

### CalendarWidget
월/주 캘린더 컨테이너. 내부에 [[#CalendarRow]]와 [[#ScheduleLine]]을 가진다. 디자인: [[캘린더_패널]].

### ChatWidget
[[공통_AI대화창]] UI 전체 컨테이너. 디자인: [[AI_채팅_패널]].

### ToastWidget
알림 토스트. 디자인: [[토스트_모달]].

### ModalWidget
확인 모달. 디자인: [[토스트_모달]].

### BriefingPanel
오늘의 정원 메시지 영역(홈).

## 서비스 클래스

### ThemeManager

- 테마 키와 팔레트, 시즌 자동 판정. 또한 [[디자인_시스템]]의 모든 토큰(컬러/타이포/간격/라운드/그림자/모션)을 보관한다.
- 멤버: `tokens`(dict 트리), `variant`(현재 테마 키)
- 메서드: `set_theme(variant)`, `color(key)`, `text_style(key)`, `space(key)`, `radius(key)`, `shadow(key)`, `motion(key)`, `auto_pick_by_date()`.

### SoundManager

- 효과음, BGM, 볼륨.
- 메서드: `play_sfx`, `play_bgm`, `stop_bgm`, `set_volume`.

## 디자인 / 렌더 보조

### FontRegistry

- 폰트 파일 + 크기 조합을 캐싱.
- 메서드: `get(font_key, size)`, `preload(list)`.

### TextRenderer

- 멀티라인, 말줄임(`...`), 정렬(left/center/right).
- 메서드: `draw(surface, text, style_key, rect, color_key)`, `measure(text, style_key)`, `wrap(text, width, style_key)`.

### ShadowRenderer

- 라운드 사각형 그림자 렌더링. [[그림자_효과#그림자]].
- 메서드: `draw_box_shadow(surface, rect, radius, shadow_key)`.

### Animator

- 시간 기반 보간(트윈).
- 메서드: `tween(target, prop, to, duration_key, easing)`, `update(dt)`.

### LayoutTokens

- [[간격_레이아웃]]의 토큰을 코드에서 참조하는 헬퍼.

### GridHelper

- 12 컬럼 그리드의 col→픽셀 변환.
- 메서드: `cols(span, total_width, gutter)`.

### AssetLoader

- [[픽셀_에셋#폴더-구조]]의 모든 이미지/폰트를 인덱싱하고 lazy 로드.
- 메서드: `load_image(path)`, `load_font(key)`, `pixel(path)`, `iter_floor_tiles()`.

### PlantSprite

- [[픽셀_에셋#식물-합성]] 규칙에 따라 한 식물을 합성/캐싱.
- 메서드: `render(species, status, progress, size)`, `render_thumbnail(size)`.

### PlantSway

- 잎/꽃의 미세 흔들림 애니메이션.
- 메서드: `update(dt)`, `offset_for(layer)`.

### PixelSprite

- 단일 픽셀 이미지를 그릴 때 nearest-neighbor 스케일 보장.
- 메서드: `draw(surface, pos, scale)`.

## 디자인 구현 위젯

> [[디자인_시스템]]의 컴포넌트에 1:1 대응하는 구현 클래스들.

### Sidebar
세로 내비게이션 컨테이너. 자식: 로고, [[#IconButton]] 목록, 하단 + 버튼. 디자인: [[사이드바]].

### TopBar
페이지 제목 + 서브타이틀 + [[#SearchInput]]. 디자인: [[상단바]].

### SummaryCard / SummaryCardsRow
[[통계_카드]] 구현체. 홈 상단 카드 영역.

### PlantBoard
[[홈]]의 식물 카드 그리드 컨테이너.

### PlantCard
[[식물_카드]] 구현체. 홈 식물 보드의 미니 카드.

### PlantWidget
[[식물_정원_레이아웃]]에서 정원 풍경의 한 식물(화분 + 픽셀 합성 식물). 내부 합성은 [[#PlantSprite]] 사용.

### PlantStage
[[식물#식물-상세]]에서 식물 일러스트 위에 [[#BudWidget]]들을 배치하는 무대(stage). [[#PlantWidget]]과 다르며, 식물 상세 화면에서만 쓰인다.

### CalendarRow / ScheduleLine
[[캘린더_패널]]의 일자 행과 일정 라인.

### WiltingCard / WiltingSection
[[시들_카드]] 구현체. 시들고 있는 봉우리 목록.

### ChatHeader / ChatMessageBubble / NextActionCard / QuickAskRow / AttachmentSheet / ChatInput
[[AI_채팅_패널]] 구현체.

### FilterChip / StatusBadge / ChipRow
[[칩_뱃지]] 구현체.

### Button / IconButton
[[버튼]] 구현체.

### TextInput / SearchInput / PasswordInput
[[입력창]] 구현체.

### TabList / FormCard / Toggle / Slider / Dropdown
[[설정_레이아웃]]의 설정 폼 위젯.

### GardenLayout / GrassFloor / PlantLabel
[[식물_정원_레이아웃]]의 정원 풍경 구성. 정원 풍경 안에서 식물 하나는 [[#PlantWidget]]이 담당한다.

## 메모

- 위 클래스/멤버는 구현이 시작되면 정밀해진다. 이 사전은 문서 간의 참조 일관성을 유지하기 위한 명명 합의이다.
- 새 클래스/멤버를 도입할 때는 반드시 이 파일에 항목을 추가하고 다른 문서가 사용할 수 있는 wikilink 앵커를 보장한다.
